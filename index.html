Featured Graph AI

FinGuard-GNN

End-to-end financial crime detection combining Graph Neural Networks for money-flow analysis with LLM-generated risk narratives. Detects mule accounts in real time with full transaction-level explainability.

Architecture

Transactions are modelled as a heterogeneous graph (accounts = nodes, fund transfers = edges). A GNN learns structural embeddings that expose mule networks; high-risk subgraphs are passed to a GPT-4 chain to produce plain-English risk summaries reviewed by fraud analysts.

Featured RAG / LLM

RAGDoc Intelligence

Retrieval-Augmented Generation system for semantic querying of 50,000+ financial regulatory documents — cuts compliance review time by 70% via cited LLM-powered summarisation and Q&A.

Architecture

Regulatory PDFs are chunked, embedded with text-embedding-3-large, and stored in ChromaDB. A LangChain RetrievalQA chain retrieves top-k chunks per query and synthesises accurate, cited answers — with strict prompt guardrails to prevent hallucination on compliance-critical content.

Deep Learning

AnomalyFormer

Novel Transformer architecture for detecting anomalies in high-dimensional IoT sensor streams. Trained on 500M+ data points across industrial plant zones with sub-100ms inference latency.

Architecture

A Patch-TST-inspired Transformer segments multivariate sensor time series into patches and learns cross-sensor correlations via multi-head self-attention. Anomalies are flagged by reconstruction-error thresholding, deployed on Kafka Streams for exactly-once, sub-100ms processing at plant scale.

Featured LLM + RAG

LLM-KYC Copilot

Intelligent KYC automation using RAG over customer identity documents and LLM-based risk classification. Cuts manual review effort by 65% while maintaining full regulatory compliance.

Architecture

Identity documents are OCR-parsed and chunked; Pinecone stores the embeddings. The RAG pipeline surfaces relevant sections for the LLM, which classifies risk tier (Low / Medium / High) and generates a structured KYC report — with a mandatory human-in-the-loop review gate before decisions are finalised.

Real-time ML

DeepFraud Sentinel

Production-grade real-time fraud detection engine handling 10K+ TPS at <50ms latency — combining gradient boosting with deep learning for sequential behavioural anomaly detection.

Architecture

Two-stage pipeline: XGBoost scores each transaction at ingestion (fast path, <10ms), while a BiLSTM tracks 30-transaction behavioural sequences (deep path). Scores are ensembled and decisions orchestrated on Apache Flink with exactly-once processing guarantees at scale.

MultiModal AI

MultiModal Risk Engine

Multi-modal deep learning system fusing document OCR, computer vision, and structured tabular data for insurance fraud detection — 45% fewer false positives vs. single-modality baselines.

Architecture

ResNet-50 processes claim photos for damage assessment; BERT encodes claim text and form fields; LightGBM handles structured tabular features. A late-fusion attention layer combines all three modality embeddings, trained end-to-end with a custom focal loss to handle severe class imbalance.
