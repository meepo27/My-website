Parameters:

Name | Type | Description | Default  
---|---|---|---  
  
###  `num_trees` Â¶

|  `int` |  The number of trees, defaults to 100. |  `100`  
  
###  `max_depth` Â¶

|  `int` |  The depth of each tree, defaults to 20. |  `20`  
  
###  `split_criteria` Â¶

|  `str` |  Split criteria for categorical values, can be "All vs all", or "One vs others". Defaults to "One vs others". |  `'One vs others'`  
  
###  `min_instance_split` Â¶

|  `int` |  The minimum number of split instances, defaults to 2. |  `2`  
  
###  `in_bag` Â¶

|  `float` |  The ratio used for sampling data into the training, defaults to 0.65. |  `0.65`  
  
###  `features_per_split` Â¶

|  `int` |  The number of features per split, defaults to 0 which represents sqrt(N). |  `0`  
  
###  `undersampling` Â¶

|  `float` |  The value for undersampling. Only this or oversampling can be used. |  `None`  
  
###  `oversampling` Â¶

|  `float` |  The value for oversampling. Only this or undersampling can be used. |  `None`  
  
###  `seed` Â¶

|  `int` |  The seed value. |  `None`  
  
###  `ignored_fields` Â¶

|  `set of str` |  Set of names corresponding to the fields to be ignored when training a model. |  `None`  
  
###  `schema` Â¶

|  `[Schema](../../schema/#ds_api.schema.Schema "            Schema \(ds_api.schema.Schema\)")` |  Pass a schema to enable conversion between descs and internal names. By not passing a schema, ds-api will assume field names are references to internal Pulse names, not the ones in the UI. |  `None`
