###  `` get_feature_importance_results Â¶
    
    
    get_feature_importance_results(target_value: str | bool | int) -> DataFrame
    

Extract the results of the absolute and relative feature importance evaluated in terms of #Recall and $Recall. Feature importance based on $Recall is only available if a cost field has been defined in the model evaluation config.

Parameters:

Name | Type | Description | Default  
---|---|---|---  
  
####  `target_value` Â¶

|  `(str, bool, int or float)` |  The target value for which the feature importance results will be extracted. |  _required_  
  
Returns:

Type | Description  
---|---  
`DataFrame` |  Pandas df with feature importance results, ordered by descending values of the #Recall-based feature importance.  
  
Examples:
    
    
    >>> model_eval.get_feature_importance_results('true')

###  `` run_feature_importance Â¶
    
    
    run_feature_importance(desired_fpr: float = 0.01, sample_rate: float = 0.3, random_seed: int | None = None, job_profile: [JobProfile](../job_profile/#ds_api.job_profile.JobProfile "            JobProfile \(ds_api.job_profile.JobProfile\)") | None = None, job_properties: dict[str, str] | None = None, wait: bool = False) -> None
    

Run feature importance on the model evaluation object.

The values of the features are shuffled, and the loss in (transaction or cost) Recall with respect to the true Recall is computed, for each feature individually.

Parameters:

Name | Type | Description | Default  
---|---|---|---  
  
####  `desired_fpr` Â¶

|  `float` |  The desired FPR for feature importance. Defaults to 0.01. |  `0.01`  
  
####  `sample_rate` Â¶

|  `float` |  Sampling rate to be applied prior to feature importance. Defaults to 0.3. |  `0.3`  
  
####  `random_seed` Â¶

|  `int` |  Random seed, for reproducibility purposes. Defaults to a random integer between 1 and 1000000. |  `None`  
  
####  `job_profile` Â¶

|  `[JobProfile](../job_profile/#ds_api.job_profile.JobProfile "            JobProfile \(ds_api.job_profile.JobProfile\)")` |  Pulse UI custom job profile. |  `None`  
  
####  `job_properties` Â¶

|  `Mapping of str` |  Map of spark configurations for the job. Defaults to Pulse's Properties Profile. |  `None`  
  
####  `wait` Â¶

|  `bool` |  Waits or not for feature importance to end. Defaults to False. |  `False`  
  
Examples:
    
    
    >>> model_eval.run_feature_importance()
    >>> # or
    >>> model_eval.run_feature_importance(
    ...     desired_fpr=0.01,
    ...     sample_rate=0.3,
    ...     random_seed=123456
    ... )
    >>> # or
    >>> model_eval.run_feature_importance(
    ...     desired_fpr=0.01,
    ...     sample_rate=0.3,
    ...     random_seed=123456,
    ...     job_properties={"spark.executor.memory": "5g"},
    ... )
