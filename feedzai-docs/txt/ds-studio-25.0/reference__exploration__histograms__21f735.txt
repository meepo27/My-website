##  `` NumericalHistogramConfig Â¶
    
    
    NumericalHistogramConfig(minv, maxv, max_bins=1000)
    

Bases: `object`

Configuration object for numerical histograms.

It requires three configurable values: minv/maxv the minimum and maximum histogram values, and max_bins the number of bins or resolution of the histogram.

The minv and maxv configurables are private accessible via get_minmax() and set_minmax(), while nbins is a property.

Parameters:

Name | Type | Description | Default  
---|---|---|---  
  
###  `minv` Â¶

|  |  minimum value of the histogram. Smaller values will be counted in the underflow bin. |  _required_  
  
###  `maxv` Â¶

|  |  maximum value of the histogram. The last bin is closed on the right side, i.e. entries with value == maxv will be counted in the last bin. Larger values will be counted in the overflow bin. |  _required_  
  
###  `max_bins` Â¶

|  |  resolution of the histogram, i.e. number of bins within minv and maxv. There will be two extra bins to account for underflow and overflow. |  `1000`

##  `` compute_all_histograms Â¶
    
    
    compute_all_histograms(data: _TDataFrame, field_bin_exprs: list[Tuple[str, Column, Callable]], breakdown_cols: list[Column], breakdowns: list[str]) -> dict[str, dict]
    

Compute histograms for all fields in a single pass:

  1. Builds an array-of-structs with one element per field, each containing `(field_name_literal, bin_expression)`.
  2. Explodes the array so every input row produces N rows (one per field).
  3. Runs a single `groupBy("__field", "__bin", *breakdowns).count()`.
  4. Partitions the collected rows back into per-field histogram dicts using the field-specific _decode_fn_.



Parameters:

Name | Type | Description | Default  
---|---|---|---  
  
###  `data` Â¶

|  `DataFrame` |  Source DataFrame. |  _required_  
  
###  `field_bin_exprs` Â¶

|  `list of (str, Column, callable)` |  One tuple per field, as returned by `build_*_bin_expr`. Each tuple is `(field_name, bin_column_expr, decode_fn)`. |  _required_  
  
###  `breakdown_cols` Â¶

|  `list of Column` |  Pre-built breakdown column expressions for the `groupBy`. |  _required_  
  
###  `breakdowns` Â¶

|  `list of str` |  Field names corresponding to _breakdown_cols_. |  _required_  
  
Returns:

Type | Description  
---|---  
`dict[str, dict]` |  Mapping from field name to histogram dict. Each histogram dict maps `(bucket_key, breakdown_values) -> count`.
