##  `` BaseOperator Â¶
    
    
    BaseOperator(pyjnius_java)
    

Bases: `[JavaWrapper](../../../java_wrapper/#ds_api.java_wrapper.JavaWrapper "            JavaWrapper \(ds_api.java_wrapper.JavaWrapper\)")`, `ABC`

Abstract class to provide additional Python functionality to all Plan Operators.

Notes

When comparing operators we consider two operators to be the same if they are of the same type and have the same name. This allows a more intuitive comparison between plans where we want to analyze differences of "the same" operator. In such cases we need to first identify the "same" operator between plans so that then we can check how their contents are different.

For reference, `BaseOperator.getName` returns the name of the operator as it appears in the UI.
