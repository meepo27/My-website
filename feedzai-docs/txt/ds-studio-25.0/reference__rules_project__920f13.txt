###  `` shift_rule Â¶
    
    
    shift_rule(rule: str, find_by: str, offset: int) -> None
    

Moves the rule the number of positions specified by the offset.

This will in shift this rule in the rules project's ordered list of rules, copying the rule order value between affected rules. Therefore, even if the order values are not continuous (e.g. 1, 3, 5) they will be preserved as a whole but assigned to different rules (i.e. after any shift the order values will still be 1, 3 and 5).

A rule will only be shifted forward (positive offset) or backwards (negative offset) at most until it reaches the end or beginning of the list, respectively - i.e. the list is not treated like a circular buffer.

Parameters:

Name | Type | Description | Default  
---|---|---|---  
  
####  `rule` Â¶

|  `str` |  The value of the rule property, specified by `find_by`, which identifies the rule to shift. |  _required_  
  
####  `find_by` Â¶

|  `('id', 'desc')` |  Name of the property of rules, which uniquely identifies the rule to shift, whose value is provided by the `rule`:

  * 'id' : shift rule with the given id.
  * 'desc' : shift rule with the given user visible name.

|  `'id'`  
  
####  `offset` Â¶

|  `int` |  The number of positions to move the rule. It can be positive to move the rule `offset` positions forward or negative to move it backwards. |  _required_

Possible types of tenancy for rules projects.

###  `` MULTI_TENANT_DISTINCT `class-attribute` `instance-attribute` Â¶
    
    
    MULTI_TENANT_DISTINCT = auto()
    

Multi-tenant distinct. Each tenant may have its individual rules.

###  `` MULTI_TENANT_SHARED `class-attribute` `instance-attribute` Â¶
    
    
    MULTI_TENANT_SHARED = auto()
    

Multi-tenant shared. Rules are common to all tenants but are processed independently by each tenant. This means events are filtered by tenant on evaluations, and that on stateful rules each tenant has a dedicated rules engine.

###  `` SINGLE_TENANT `class-attribute` `instance-attribute` Â¶
    
    
    SINGLE_TENANT = auto()
    

Single tenant, the default. There is no tenant segregation.
