History-preserving stratified random undersampling strategy.

Constructor for StratifiedRandomUndersampler.

The random undersampling is performed according to one (and only one) of the following options to be specified: `fraction`, `balance`, `n`.

Note

It is not guaranteed to provide _exactly_ the specified fraction/balance/n.

###  `target_value` Â¶

|  `(bool, int, str or set)` |  Name of class associated with the positive class in `target_field`. This class will be maintained complete. It can be a set of classes to represent that all those classes should be kept complete without sampling. |  _required_  
  
###  `fraction` Â¶

|  `float` |  Specifies the fraction of the negative class to be sampled. All instances from the positive class will be kept. |  `None`  
  
###  `balance` Â¶

|  `float` |  Specifies the desired target balance. E.g. 0.9 means that the positive:negative ratio will be 1:9. All instances from the positive class will be kept, while the negative class will be sampled in order to result in the specified balance ratio. |  `None`  
  
###  `n` Â¶

|  `int` |  Specifies the number of instances to sample from the negative class. All instances from the positive class will be kept. |  `None`

####  `optimal_recovery` Â¶

|  `bool` |  Indicates whether optimal recovery should be performed. If set to False, full recovery will be used instead. Only applicable if `entity_field` is given. Default value is 'True'. If 'True', 'timestamp_field' and 'recovery_days' are mandatory. |  `True`

####  `entity_fields` Â¶

|  `list` |  List of field names for which recovery should occur. Alternatively, can be a list of tuples (field, recovery_days) if different windows are to be applied to each of the fields. Examples:

This examples demonstrates the behaviour of the option exclude_kickoff_window.
    
    
    >>> first_timestamp = df.agg(F.min(timestamp_field)).first()[0]
    >>> datetime.fromtimestamp(first_timestamp/1000)
    2018-12-20 09:27:53
    >>> window_size = 7 #days
    >>> df_sampled = sampler.sample(
    ...     df,
    ...     mark_field='ismarked',
    ...     exclude_kickoff_window = True,
    ...     timestamp_field='timestamp',
    ...     recovery_days=window_size,
    ... )
    >>> first_marked_timestamp = (
    ...     df.filter(col(is_marked)).
    ...     agg(F.min(timestamp_field)).first()[0]
    ... )
    >>> datetime.fromtimestamp(first_marked_timestamp/1000)
    2018-12-27 10:15:48
    >>> MS_PER_DAY = 24*60*60*1000
    >>> first_marked_timestamp >= first_timestamp + max_window*MS_PER_DAY
    True
