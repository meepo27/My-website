###  `` get_spark_local_session `staticmethod` Â¶
    
    
    get_spark_local_session(spark_params: Optional[Mapping[str, str]] = None, spark_app_name: Optional[str] = None, log_level: SparkLogLevel = ERROR)
    

Get SparkSession configured in local mode. It will use all available CPUs and each executor has 1G RAM and 1 vcore.

Note that Spark maintains a single activate session, thus unless it was crashed, you would always get the same one, but configured in local mode. Even if you stop SparkSession or SparkContext, in pySpark, it will remember previous configurations.

This means the following:

  1. Previously spark had properties A, B, and C defined
  2. You call this function and you will get a SparkSession with A, B, and C defined as well as the local mode

###  `` get_spark_session Â¶
    
    
    get_spark_session(spark_params: Dict[str, str] | None = None, exclude_spark_params: List[str] | None = None, app_name: str | None = None, spark_app_name: str | None = None, job_profile_name: str | None = None, group_name: str | None = None, clean_spark_properties: bool = True, log_level: SparkLogLevel = ERROR, session_type: SparkSessionType = CLASSIC, spark_remote: str | None = None)
    

Get SparkSession with default Pulse's configuration.

Note that Spark maintains a single activate session, thus unless it was crashed, you would always get the same one, but with last Pulse's configuration (and possible old configurations). Even if you stop SparkSession or SparkContext, in pySpark, it will remember previous configurations.

This means the following:

  1. Pulse has properties A, B, and C defined
  2. You call this function and you will get a SparkSession with A, B, and C properties
  3. You remove property A and add property D
  4. You call this function and you will get a SparkSession with **A** , B, C, and D

###  `` pyspark_to_pulse `staticmethod` Â¶
    
    
    pyspark_to_pulse(spark_session: _TSparkSession, dataframe: _TDataFrame, app: [App](../app/#ds_api.app.App "            App \(ds_api.app.App\)"), name: str, path: str, file_format: str = 'csv', schema: Optional[[Schema](../schema/#ds_api.schema.Schema "            Schema \(ds_api.schema.Schema\)")] = None, **kwargs: Union[bool, str, int, Dict[str, Any], Set[str]])
    

Uses ds_api.SparkDataSourceAdapter to convert a given pySpark dataframe to a Pulse datasource.

The dataframe will be written in the path specified before being added to Pulse. DateType and TimestampType fields are written as unix time (in seconds). The schema will be automatically inferred using AbstractDataSource#inferSchema approach if the Schema is not specified.

All pySpark types but DecimalType and MLlib types are supported.
