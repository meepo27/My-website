##  `` SparkDatasourceAdapter Â¶
    
    
    SparkDatasourceAdapter(spark_session)
    

Bases: `object`

A class that follows the adapter pattern. This class is responsible for:

  * adapting pulse data sources into spark dataframes, through `from_pulse_datasource`
  * adapting spark dataframes into pulse data sources, through `to_pulse_datasource`

###  `` to_pulse_datasource Â¶
    
    
    to_pulse_datasource(dataframe: _TDataFrame, app: [App](../../app/#ds_api.app.App "            App \(ds_api.app.App\)"), name: str, path: str, file_format: str = 'csv', schema: Optional[[Schema](../../schema/#ds_api.schema.Schema "            Schema \(ds_api.schema.Schema\)")] = None, **kwargs: Union[bool, str, int, Dict[str, Any], Set[str]])
    

Adapts a pyspark dataframe into a pulse datasource. The dataframe will be written in the path specified before being added to Pulse. DateType and TimestampType fields are written as unix time (in milliseconds). The schema will be automatically inferred using AbstractDataSource#inferSchema approach if the Schema is not specified.

All pySpark types but DecimalType and MLlib types are supported.

`has_header` |  `bool` |  Flags whether the dataset is to be read with header. Only used for csv files. Defaults to True.  
`sep` |  `str` |  Delimiter to use. Should contain exactly one character. Only used for csv files. Defaults to ','.  
`missing_values` |  `set of str` |  Set of strings with values for empty value. Only used for csv files. Defaults to {"", "NA", "NULL"}.  
`quote` |  `str` |  The character used to denote the start and end of a quoted item. Only used for csv files. Defaults to "'".  
`line_separator` |  `str` |  The string used mark the end of line. Only used for csv files. Defaults to "\n".  
`encoding` |  `str` |  Encoding to use for UTF when reading/writing. Only used for csv files. Defaults to 'UTF-8'.  
`cat_threshold` |  `int` |  A value that represents the maximum number of distinct values on a given field for it to be inferred as categorical. Defaults to 15. Will only be used if no Schema is specified.  
`job_properties` |  `Dict` |  The dictionary with the specific properties for the schema inference job. Will only be used if no Schema is specified. Defaults to Pulse PropertiesProfile.  
`n_records` |  `int` |  The number of records that will be read per partition when performing datasource schema inference. Will only be used if no Schema is specified. Defaults to 15000.  
`dtypes` |  ` Dict` |  The dictionary with the field overriding information when inferring the datasource schema. Will only be used for csv files and if no Schema is specified. Defaults to None.  
`merge_schemas` |  `bool` |  Specify if schema merging should be allowed. Only used for parquet files. Defaults to False. See: https://spark.apache.org/docs/latest/sql-data-sources-parquet.html#schema-merging
