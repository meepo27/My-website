#  `` lists Â¶  
  
DS-API module to manage lists and list items in Pulse.

A List in Pulse is either Simple (`SimpleManagedListModel`) or Complex (`ComplexManagedListModel`). A Pulse List can contain items of the respective type: `SimpleManagedListItemModel` or `ComplexManagedListItemModel`.

Additionally, lists can have tags (`ManagedListTagModel`).

This module also provides a wrapper for `ManagedList`, to simplify list operations like `delete()`, and to provide an API that is more consistent with the rest of the DS-API.

##  `` ManagedList Â¶
    
    
    ManagedList(pyjnius_java)
    

Bases: `[JavaWrapper](../java_wrapper/#ds_api.java_wrapper.JavaWrapper "            JavaWrapper \(ds_api.java_wrapper.JavaWrapper\)")`

Wrapper for Pulse's Lists. Can handle all list types.

Although one can use the Pulse API directly by accessing the methods of the managed list wrapped by this class with `getManagedList()`, this Python wrapper pulls all those methods to the main class.

Any method implemented by `ManagedList` takes precedence over exposed `self.getManagedList()._java_attributes()` members, to allow ManagedList to implement custom behaviour that overrides the wrapped class's members.
