##  `` Split `dataclass` Â¶
    
    
    Split(name: str, start_timestamp: Optional[Union[int, datetime]] = None, end_timestamp: Optional[Union[int, datetime]] = None, path: Optional[str] = None)
    

Defines a datasource split.

Attributes:

Name | Type | Description  
---|---|---  
`name` |  `str` |  Name of the datasource created by the split  
`start_timestamp` |  `(optional, int or datetime)` |  Timestamp starting the splitting interval. If not specified, the beginning of the dataset will be included and end_timestamp must be specified.  
`end_timestamp` |  `(optional, int or datetime)` |  Timestamp ending the splitting interval. If not specified, the end of the dataset will be included and start_timestamp must be specified.  
`path` |  `(optional, str)` |  The writing path for the split.
