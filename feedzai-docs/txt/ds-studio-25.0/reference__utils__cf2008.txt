##  `` create_spark_app_name Â¶
    
    
    create_spark_app_name() -> str
    

Creates an application name for spark.

The created name will take in consideration the following aspects:

  1. If the env variable ds_api.USER_NAME_ENV is defined, then it will be used as part of the created name. This environment variable is assumed to contain the name of the user that spawned the current process.
  2. If the env variable in 1) is not defined, then the env variable ds_api.USER_ID_ENV will be used (if defined) as part of the created name. This environment variable is assumed to contain the identifier of the user that spawned the current process.
  3. If the env variable in 2) is not defined, then this function calls os.getpid, and uses such pid in the created application name.



Returns:

Type | Description  
---|---  
`str` |  A spark application name.
