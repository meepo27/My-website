##  `` Validation Â¶
    
    
    Validation(desc: str, semantic: Tag, sql_builder: Callable[[Column], Column], warning_fn: Callable[[int], bool] = lambda x: x > 0)
    

Bases: `object`

Class that represents a descriptive validation to be computed. These validations will be computed in a map and reduce approach.

Parameters:

Name | Type | Description | Default  
---|---|---|---  
  
###  `desc` Â¶

|  `str` |  the description/name of the validation. |  _required_  
  
###  `semantic` Â¶

|  `Tag` |  the semantic type to be applied to, e.g. Tag("AMOUNT", FieldType.NUMERICAL). |  _required_  
  
###  `sql_builder` Â¶

|  `Callable[[Column], Column]` |  Factory that receives a Spark `Column` and returns the Spark SQL validation expression |  _required_  
  
###  `warning_fn` Â¶

|  `Callable[[int], bool]` |  the function to be used to asses when a validation should be alerted. |  `lambda x: x > 0`
