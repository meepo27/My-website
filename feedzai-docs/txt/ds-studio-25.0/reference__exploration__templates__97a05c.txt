##  `` make_freq_table Â¶
    
    
    make_freq_table(freq_table)
    

Function that returns a formatted HTML code corresponding to a frequency table.

:param freq_table: Pandas Series containing the frequency table. Indices are the category labels, values are the frequencies. :returns: frequency table in formatted HTML code.
