###  `` diff_dicts_html Â¶
    
    
    diff_dicts_html(dicts_1: List[Dict], dicts_2: List[Dict], join_keys: List[str], headers: List[str] | None = None, only_diff: bool = True) -> str
    

Finds the differences between two lists of dictionaries.

Differences can be either updates, additions or deletions and are formatted side by side in an HTML table. Updates take place if the values of 'join_keys' are equal.

Parameters:

Name | Type | Description | Default  
---|---|---|---  
  
####  `dicts_1` Â¶

|  `list of dict` |  List of dicts to be compared. |  _required_  
  
####  `dicts_2` Â¶

|  `list of dict` |  List of dicts to be compared. |  _required_  
  
####  `join_keys` Â¶

|  `list of str` |  Keys to pair dictionaries in both lists and evaluate equality. |  _required_  
  
####  `headers` Â¶

|  `list, optional, by default None` |  Headers to be displayed on the diff table, length 2. |  `None`  
  
####  `only_diff` Â¶

|  `bool, by default True.` |  Report only dictionaries with changes. |  `True`  
  
Returns:

Type | Description  
---|---  
`str` |  Differences in HTML formatted code.
