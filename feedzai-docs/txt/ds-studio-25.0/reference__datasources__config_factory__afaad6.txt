Other Parameters:

Name | Type | Description  
---|---|---  
`has_header` |  `bool` |  Flags whether the dataset is to be read with header. Defaults to True.  
`sep` |  `str` |  Delimiter to use. Should contain exactly one character. Defaults to ','.  
`missing_values` |  `set of str` |  Set of strings with values for empty value. Defaults to {"", "NA", "NULL"}.  
`quote` |  `str` |  The character used to denote the start and end of a quoted item. Defaults to '''  
`line_separator` |  `str` |  The string used mark the end of line. Defaults to '\n''.  
`encoding` |  `str` |  Encoding to use for UTF when reading/writing. Defaults to 'UTF-8'.  
`cat_threshold` |  `int` |  A value that represents the maximum number of distinct values on a given field for it to be inferred as categorical. Defaults to 15. Will only be used if no Schema is specified.  
`job_properties` |  `Dict` |  The dictionary with the specific properties for the schema inference job. Will only be used if no Schema is specified.  
`n_records` |  `int` |  The number of records that will be read per partition when performing datasource schema inference. Defaults to 15000. Will only be used if no Schema is specified.  
`dtypes` |  ` Dict` |  The dictionary with the field overriding information when inferring the datasource schema. Will only be used if no Schema is specified.  
`merge_schemas` |  `bool` |  Specify if schema merging should be allowed. See: https://spark.apache.org/docs/latest/sql-data-sources-parquet.html#schema-merging
