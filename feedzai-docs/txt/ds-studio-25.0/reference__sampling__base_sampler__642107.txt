##  `` BaseSampler Â¶
    
    
    BaseSampler(seed: int | None = None)
    

Bases: `ABC`

Base class for sampling implementations.

All subclasses must implement the public :meth:`sample` method.

Any additional configurations that your custom sampler needs, should be passed during instantiation.

Parameters:

Name | Type | Description | Default  
---|---|---|---  
  
###  `seed` Â¶

|  `int` |  Seed for Spark's random number generator. |  `None`  
  
Examples:
    
    
    >>> class RandomSampler(BaseSampler):
    ...     '''Custom random sampler.'''
    ...     def __init__(self, fraction: float, seed: Optional[int] = None):
    ...         self._fraction = fraction
    ...         super().__init__(seed=seed)
    ...     def sample(self, df: DataFrame) -> DataFrame:
    ...         return df.sample(fraction=self._fraction)
    >>> # Initialize the custom sampler
    >>> random_sampler_1pc = RandomSampler(0.01)
    >>> # Run it against some data
    >>> df = ...
    >>> random_sampler_1pc.sample(df)

##  `` optimal_recovery Â¶
    
    
    optimal_recovery(marked_df: _TDataFrame, entity_field: str, timestamp_field: str, recovery_days: int, recover_column_name: str, mark_field: str = MARK_FIELD) -> _TDataFrame
    

Performs optimal entity recovery over a sampled DataFrame.

That is, for a given sampled instance, it recovers the instances belonging to the same entity and falling in a relevant time period. The relevant period of time is a window before the sampled instance, defined by the recovery_days parameter.
