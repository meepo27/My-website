    IsolationForestConfig(ntrees: int = 50, sample_size: int = 100, min_rows: int = 1, max_depth: int = 8, sample_rate: float = -1.0, mtries: int = -1, nbins: int = 2, seed: int | None = None, ignored_fields: set[str] | None = None, schema: [Schema](../../schema/#ds_api.schema.Schema "            Schema \(ds_api.schema.Schema\)") | None = None)
    

Bases: `[TrainingConfig](../#ds_api.models.TrainingConfig "            TrainingConfig \(ds_api.models.TrainingConfig\)")`

The H2O Isolation Forest configuration object used for model training.

This is an unsupervised learning algorithm used for anomaly detection. The target variable will be automatically excluded from features during training.

Parameters:

Name | Type | Description | Default  
---|---|---|---  
  
###  `ntrees` Â¶

|  `int` |  Number of trees in the forest, defaults to 50. |  `50`  
  
###  `sample_size` Â¶

|  `int` |  Number of samples to use per tree, defaults to 100. |  `100`  
  
###  `min_rows` Â¶

|  `int` |  Minimum number of rows in a leaf, defaults to 1. |  `1`  
  
###  `max_depth` Â¶

|  `int` |  Maximum depth of trees, defaults to 8. |  `8`  
  
###  `sample_rate` Â¶

|  `float` |  Row sampling rate. Use -1 for automatic, defaults to -1.0. |  `-1.0`  
  
###  `mtries` Â¶

|  `int` |  Number of features to try per split. Use -1 for automatic, defaults to -1. |  `-1`  
  
###  `nbins` Â¶

|  `int` |  Number of bins for numerical features, defaults to 2. |  `2`  
  
###  `seed` Â¶

|  `int` |  The seed value. |  `None`  
  
###  `ignored_fields` Â¶

|  `set of str` |  Set of names corresponding to the fields to be ignored when training a model. |  `None`  
  
###  `schema` Â¶

|  `[Schema](../../schema/#ds_api.schema.Schema "            Schema \(ds_api.schema.Schema\)")` |  Pass a schema to enable conversion between descs and internal names.
