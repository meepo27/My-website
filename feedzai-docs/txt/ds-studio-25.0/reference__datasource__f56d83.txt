#  `` datasource Â¶

This module contains the API to interact with Pulse data sources.

Start by fetching a data source by running
    
    
    ds = app.pullDataSourceByDesc("<name as it appears in the UI>")
    

Then you can launch analyze jobs, run feature selection, call AutoML to generate features and more.

###  `` analyze Â¶
    
    
    analyze(default_breakdowns: bool = True, wait: bool = False, job_profile: Optional[[JobProfile](../job_profile/#ds_api.job_profile.JobProfile "            JobProfile \(ds_api.job_profile.JobProfile\)")] = None, job_properties: Optional[Dict[str, str]] = None) -> bool
    

Analyze this datasource with Pulse.

By analyzing a data source, Pulse will launch a job to compute approximate histograms for each numerical feature.

The default analysis configuration will also include histogram breakdowns with **all categorical variables**. For each categorical variable in the data source, there will be a new histogram in each numerical feature.

data sources with many categorical fields

It is recommended to set `default_breakdowns=False` when there are many categorical fields. Otherwise, the amount of metadata that is generated might compromise the performance of Pulse.

The datasource analysis will be run with Pulse's default config for datasource analysis.

Parameters:

Name | Type | Description | Default  
---|---|---|---  
  
####  `default_breakdowns` Â¶

|  `bool` |  Whether the analysis should include breakdowns for all categorical fields or not. Default is `True`. |  `True`  
  
####  `wait` Â¶

|  `bool` |  Whether to wait for the datasource analysis to finish. The data analysis outcome will be logged. Default is `False`. |  `False`  
  
####  `job_profile` Â¶

|  `[JobProfile](../job_profile/#ds_api.job_profile.JobProfile "            JobProfile \(ds_api.job_profile.JobProfile\)")` |  Pulse UI custom job profile. |  `None`  
  
####  `job_properties` Â¶

|  `dict` |  Additional spark properties, e.g. `{"spark.executor.memory": "1g"}`. By default, no additional spark properties are added. |  `None`  
  
Returns:

Type | Description  
---|---  
`bool` |  Whether the analysis started or not.

Name | Type | Description  
---|---|---

`missing_values` |  `set of str` |  Set of strings with values for empty value. Only used for csv files. Defaults to `{'', 'NA', 'NULL'}`.  
`quote` |  `str` |  The character used to denote the start and end of a quoted item. Only used for csv files. Defaults to `"'"`.  
`line_separator` |  `str` |  The string used mark the end of line. Only used for csv files. Defaults to `'\n'`.  
`encoding` |  `str` |  Encoding to use for UTF when reading/writing. Only used for csv files. Defaults to `'UTF-8'`.  
`cat_threshold` |  `int` |  A value that represents the maximum number of distinct values on a given field for it to be inferred as categorical. Defaults to 15.  
`job_properties` |  `Dict` |  The dictionary with the specific properties for the schema inference job. Will only be used if no Schema is specified. Defaults to Pulse PropertiesProfile.  
`n_records` |  `int` |  The number of records that will be read per partition when performing datasource schema inference. Will only be used if no Schema is specified. Defaults to 15000.  
`dtypes` |  ` Dict` |  The dictionary with the field overriding information when inferring the datasource schema. Will only be used if no Schema is specified. Defaults to None.  
`merge_schemas` |  `bool` |  Specify if schema merging should be allowed. Only used for parquet files. Defaults to False. See: [https://spark.apache.org/docs/latest/sql-data-sources-parquet.html#schema-merging]()  
  
Returns:

Type | Description  
---|---  
`DataSource` |  DataSource object corresponding to the Pulse datasource created.

###  `` run_feature_selection Â¶
    
    
    run_feature_selection(target_field: str, threshold: float = 0.9, sample_size: int = 200000, max_features: int | None = None, job_properties: dict[str, str] | None = None, job_profile: [JobProfile](../job_profile/#ds_api.job_profile.JobProfile "            JobProfile \(ds_api.job_profile.JobProfile\)") | None = None)
    

Run feature selection on the Datasource.

Features are selected so that the cumulative sum of the feature importance on the selected features is below the given `threshold`. A maximum of `max_features` will be returned. The feature importance is computed from an H2O GBT model run on a sample of the data.

Parameters:

Name | Type | Description | Default  
---|---|---|---  
  
####  `target_field` Â¶

|  `str` |  The field to be used as target. |  _required_  
  
####  `threshold` Â¶

|  `float` |  Threshold on the cumulative feature importance, defaults to 0.9. |  `0.9`  
  
####  `sample_size` Â¶

|  `int` |  Sample size, defaults to 200,000. |  `200000`  
  
####  `max_features` Â¶

|  `int` |  Maximum number of features to return, defaults to Inf. |  `None`  
  
####  `job_properties` Â¶

|  `Mapping of str` |  Map of spark configurations for the job. If not provided defaults to the config of the current spark session. |  `None`  
  
####  `job_profile` Â¶

|  `[JobProfile](../job_profile/#ds_api.job_profile.JobProfile "            JobProfile \(ds_api.job_profile.JobProfile\)")` |  Pulse UI custom job profile. |  `None`  
Notes

If both job_properties and job_profile are specified and there is intersection between their properties, the job_properties property will overwrite the job_profile property.

Returns:

Type | Description  
---|---  
`set of str` |  The selected features.  
  
Examples:
    
    
    >>> selected_features = datasource.run_feature_selection(
    ...     target_field="target"
    ... )
    >>> job_profile = app.pullJobProfileByDesc("job_profile_name")
    >>> selected_features = datasource.run_feature_selection(
    ...     target_field="target",
    ...     threshold=0.7,
    ...     sample_size=1_000_000,
    ...     max_features=20,
    ...     job_properties={
    ...         "spark.master": "yarn",
    ...         "spark.app.name": "Feature Selection",
    ...         "spark.executor.memory": "1g",
    ...         "spark.dynamicAllocation.enabled": "True",
    ...         "spark.dynamicAllocation.maxExecutors": "4",
    ...     }
    ... )
    >>> selected_features = datasource.run_feature_selection(
    ...     target_field="target",
    ...     threshold=0.7,
    ...     sample_size=1_000_000,
    ...     max_features=20,
    ...     job_profile=job_profile
    ... )
