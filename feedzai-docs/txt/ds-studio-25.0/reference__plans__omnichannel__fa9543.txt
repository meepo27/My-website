##  `` Channel `dataclass` Â¶
    
    
    Channel(name: str, schema_model: [JavaWrapper](../../java_wrapper/#ds_api.java_wrapper.JavaWrapper "            JavaWrapper \(ds_api.JavaWrapper\)"), timestamp_field: str, id: str | None = None)
    

Immutable representation of a Channel configuration for Omnichannel Plans.

Note that this can be instantiated with a `SchemaModel` directly or with a `ds_api.schema.Schema`.

Examples:
    
    
    >>> from ds_api.plans.omnichannel import Channel
    >>> app = ...
    >>> schema = app.pullSchemaByDesc("Cards Schema")
    >>> channel = Channel("cards", schema, "event_occurred_at")
    

Attributes:

Name | Type | Description  
---|---|---  
`name` |  `str` |  Name of the channel.  
`schema_model` |  `SchemaModel` |  Simple schema representation.  
`timestamp_field` |  `str` |  The name of the timestamp field as it appears in the UI.  
`id` |  `(str, optional)` |  Unique identifier for the channel. If none is passed, the ID is automatically generated when interacting with Pulse.
