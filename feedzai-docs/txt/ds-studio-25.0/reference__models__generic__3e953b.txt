|  `int` |  The seed value. |  `None`  
  
###  `ignored_fields` Â¶

|  `set of str` |  Set of names corresponding to the fields to be ignored when training a model. |  `None`  
  
###  `schema` Â¶

    >>> # training an H2O Gradient Boosting Machine
    >>> model_config = GenericConfig(
    ...     name="Gradient Boosting Machine",
    ...     provider="H2O",
    ...     parameters={
    ...         "col_sample_rate": "0.9",
    ...         "max_depth": "5",

    ...         "nbins": "20",

    ...         "ntrees": "50",
    ...     },

    ... )

    ...     "model_name",
    ...     datasource,
    ...     "target_field",
    ...     model_config
    ... )
    >>> model.waitUntilModelTrained()
    >>> config_from_model = model.get_config()
