##  `` PlanDiff Â¶
    
    
    PlanDiff(plan_a: [Plan](../../plan/#ds_api.plan.Plan "            Plan \(ds_api.plan.Plan\)"), plan_b: [Plan](../../plan/#ds_api.plan.Plan "            Plan \(ds_api.plan.Plan\)"))
    

Encapsulates the logic to find the difference between two plans.

Note

The generated diff plan allows the difference between two plans to be executed. This means it not only has the diff but also all the relevant ancestors required to make the plan valid, as well as any downstream features that would be impacted by upstream changes.

Let's say feature X changed. We need to include:

  * Feature X's ancestors to allow the computation of X.
  * Feature X's descendants because they need to be updated.
  * Feature X's descendants ancestors to make the plan valid.

Validate if two plans are compatible.

Two conditions must be met for two plans to be compatible:

  1. Same schema
  2. Same timestamp field.
