Bases: `[JavaEnumWrapper](../java_enum_wrapper/#ds_api.java_enum_wrapper.JavaEnumWrapper "            JavaEnumWrapper \(ds_api.java_enum_wrapper.JavaEnumWrapper\)")`

The type of parameters of a rules project action parameter.

This allows the user that defines an action to characterize the parameters with a type. With this type, the screens that allow users to trigger an action will also be able to have an optimized UI to provide a better UX.
