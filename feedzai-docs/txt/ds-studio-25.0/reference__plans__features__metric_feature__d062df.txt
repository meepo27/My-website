#  `` metric_feature Â¶  
  
This module implements the concrete `MetricFeature` that allows the manipulation of metrics in plans.

From an API perspective there are two properties that even though are persisted at the "metric level", they have to be defined and managed at the operator/plan level":

  1. `filter_incomplete_instances`: When true, the output of the Metrics **operator** will exclude instances whose timestamp is older than the period defined by the start of the dataset and the largest window.
  2. `timestamp_field`: Defined at the **plan** level in deployable plans.

Parameters:

Name | Type | Description | Default  
---|---|---|---  
  
###  `name` Â¶

|  `str` |  Name of the metric feature. |  _required_  
  
###  `groupby_fields` Â¶

|  `list of str` |  Fields to group by. |  _required_  
  
###  `aggregation` Â¶

|  `str` |  Aggregation expression. Aggregations must be written in PQL: "avg","min","max","count","countDistinct","sum","stddev", "last","first","prev",... Fields must be enclosed with the pattern `${field}` eg. `'avg(${amount})'`, `'countDistinct(${MerchantCity})'`, `'count()'`. **Note that "advanced" aggregations are not compatible with Railgun**. |  _required_  
  
###  `window_size` Â¶

|  `str` |  Window expression. Typically, "1 day", "4 weeks", etc. |  _required_  
  
###  `is_real_time` Â¶

|  `bool` |  True = Real time window, False = Scheduled window. True by default. |  `True`  
  
###  `scheduled_cron_expression` Â¶

|  `str` |  If is_real_time = False, a cron expression must be specified to define the periodicity of the window, by default None e.g. `'0 0 0 * * ?'` for a scheduled window running every day at midnight. |  `None`  
  
###  `filter_metric` Â¶

|  `str` |  Filter expression, by default None. Fields must be enclosed with the pattern `${field}` eg. `"${TransactionAmount} > 100 and ${Fraud} != false"`. |  `None`  
  
###  `delay` Â¶

|  `int` |  Defines delay in milliseconds, must be greater than 1000, by default None. |  `None`  
  
###  `is_tumbling` Â¶

|  `bool` |  Tumbling window, by default False. |  `False`  
  
###  `is_infinite` Â¶

|  `bool` |  When True, this metric will be considered a "non-windowed" metric. _Requires Pulse 25.0.89._ **Experimental Feature.** |  `False`  
  
###  `description` Â¶

|  `str` |  Metric description, by default None. |  `None`  
  
###  `lookup_fields` Â¶

|  `list of str` |  Lookup fields, ie the fields used to query the aggregation. By default these are set to be the same as the `groupby_fields`. When different, it means that one can execute a query like: `group by sender -> lookup by receiver`. _Experimental feature._ |  `None`  
  
###  `main_channel_contributes` Â¶

|  `bool` |  When false, the main channel does not contribute to the aggregation. True by default. _Omnichannel feature_. |  `True`  
  
###  `secondary_channels` Â¶

|  `dict[str, MetricSecondaryChannelConfig]` |  Mapping of channel ID to a `MetricSecondaryChannelConfig`. Empty by default, ie no secondary channels configured. _Omnichannel feature_. |  `None`  
  
###  `cascaded_scheduled_metrics` Â¶

|  `bool` |  When True, it indicates this feature is in a plan with cascading scheduled metrics that depend on each other. False by default. |  `False`  
  
###  `coalesce` Â¶

|  `float or int or str` |  Coalesce value for when the metric aggregation is empty. |  `None`  
  
Raises:

Type | Description  
---|---  
`ValueError` |  If is_real_time = False and scheduled_cron_expression is None. If the timestamp field from the schema is not specified in the Plan. If delay is less than 1000 ms.

###  `` get_default_naming Â¶
    
    
    get_default_naming() -> str
    

Returns a default name based on its configuration.

Default naming: `lowercase({groupby_fields}_{aggregation}_ {aggregation fields}_{window size}_{is_real_time})` eg. accountid_avg_amount_1h_rt. Advanced aggregations will be named: `lowercase({groupby_fields}_agg_ {window size}_{is_real_time})`

In the case of "advanced" window expressions, the window expression is omitted from the name.

Railgun compatibility

Note that "advanced" window expressions are not compatible with Railgun. Please use only the appropriate set of window expressions.

Type | Description  
---|---  
`str` |  Default name
