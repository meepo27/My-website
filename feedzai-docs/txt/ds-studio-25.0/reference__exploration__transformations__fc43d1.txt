##  `` aggregate_function_over_time Â¶
    
    
    aggregate_function_over_time(df, time_field, field_name, aggregate='avg', time_resolution='1 day')
    

Function to process a PySpark DataFrame, computing a given aggregate function on a given field over time windows defined by a time resolution.

Parameters:

Name | Type | Description | Default  
---|---|---|---  
  
###  `df` Â¶

|  |  PySpark DataFrame. It should contain at least two columns, one with the value of time_field as column name and another with the value of field_name. |  _required_  
  
###  `time_field` Â¶

|  |  name of the PySpark DataFrame column associated to the time field. |  _required_  
  
###  `field_name` Â¶

|  |  name of the PySpark DataFrame column associated to the field used to calculate the aggregation over. |  _required_  
  
###  `aggregate` Â¶

|  |  aggregation function to be used. The available functions are "avg", "max", "min", "sum", "count". UDF created with pyspark.sql.functions.pandas_udf() may also be used. See https:/ /spark.apache.org/docs/latest/api/python/pyspark.sql.html#pyspar k.sql.GroupedData for more details. (default: avg). |  `'avg'`  
  
###  `time_resolution` Â¶

|  |  time resolution to be used is provided as a string containing a number and an interval or a combination of those. For example, '1 day 12 hours'. Valid intervals are 'week', 'day', 'hour', 'minute', 'second', 'millisecond', 'microsecond'. All valid values for the windowDuration parameter of pyspark.sql.functions.window are accepted. See http://spark.apac he.org/docs/latest/api/python/pyspark.sql.html?highlight=window# module-pyspark.sql.functions for more details. (default: 1 day). |  `'1 day'`  
  
Returns:

Type | Description  
---|---  
`DataFrame` |  Pandas DataFrame with two columns. One is the time field column, it has the value of time_field as the column name and contains the start datetime for each time window. The second column contains the values of the aggregation function and its name is the name of the aggregation function that was used.

    count_top_n_over_time(df, time_field, field_name, top_n=5, time_resolution='1 day')
    

Function to process a PySpark DataFrame, computing the counts of the top n most frequent categories of a given string field over a time windows defined by a time resolution.

Parameters:

Name | Type | Description | Default  
---|---|---|---  
  
###  `df` Â¶

|  |  Pyspark DataFrame. It should contain at least two columns, one with the value of time_field as column name and another with the value of field_name. |  _required_  
  
###  `time_field` Â¶

|  |  name of the PySpark DataFrame column associated to the time field. |  _required_  
  
###  `field_name` Â¶

|  |  name of the PySpark DataFrame column associated to the string field used to calculate the top N values aggregation over time. |  _required_  
  
###  `top_n` Â¶

|  |  the number of the top most frequent categorical values to be drawn. |  `5`  
  
###  `time_resolution` Â¶

|  |  time resolution to be used is provided as a string containing a number and an interval or a combination of those. For example, '1 day 12 hours'. Valid intervals are 'week', 'day', 'hour', 'minute', 'second', 'millisecond', 'microsecond'. All valid values for the windowDuration parameter of pyspark.sql.functions.window are accepted. See http://spark.apac he.org/docs/latest/api/python/pyspark.sql.html?highlight=window# module-pyspark.sql.functions for more details. (default: 1 day). |  `'1 day'`  
  
Returns:

Type | Description  
---|---  
`DataFrame` |  Pandas Dataframe with three columns. One is the time field column, it has the value of time_field as the column name and contains the start datetime for each time window. The second contains the frequency counts of the top n values of the string field, over that time window, and is called "count". Lastly, the third contains the name of that categorical value, and the column name is the value of field_name.

##  `` quantiles_over_time Â¶
    
    
    quantiles_over_time(df, time_field, field_name, time_resolution='1 day')
    

Function to process a PySpark DataFrame, computing the min, max and quantiles of a given field over time windows defined by a time resolution. The quantiles are approximated, yielding a relative error of 0.01%. See https://spark.apache.org/docs/2.3.0/api/sql/index.html#percentile_approx for more details.

Parameters:

Name | Type | Description | Default  
---|---|---|---  
  
###  `df` Â¶

|  |  PySpark DataFrame. It should contain at least two columns, one with the value of time_field as column name and another with the value of field_name. |  _required_  
  
###  `time_field` Â¶

|  |  name of the PySpark DataFrame column associated to the time field. |  _required_  
  
###  `field_name` Â¶

|  |  name of the PySpark DataFrame column associated to the field used to calculate the quantiles over. |  _required_  
  
###  `time_resolution` Â¶

|  |  time resolution to be used is provided as a string containing a number and an interval or a combination of those. For example, '1 day 12 hours'. Valid intervals are 'week', 'day', 'hour', 'minute', 'second', 'millisecond', 'microsecond'. All valid values for the windowDuration parameter of pyspark.sql.functions.window are accepted. See http://spark.apac he.org/docs/latest/api/python/pyspark.sql.html?highlight=window# module-pyspark.sql.functions for more details. (default: 1 day). |  `'1 day'`  
  
Returns:

Type | Description  
---|---  
`DataFrame` |  Pandas DataFrame with six columns. One is the time field column, it has the value of time_field as the column name and contains the start datetime for each time window. The others contain the values of the min, max and the 25%, 50% and 75% quantiles. They are called min, 25%, median, 75% and max and appear in this order.
