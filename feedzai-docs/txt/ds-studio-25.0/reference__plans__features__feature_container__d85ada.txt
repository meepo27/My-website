    FeatureContainer(features: Iterable[[BaseFeature](../feature/#ds_api.plans.features.feature.BaseFeature "            BaseFeature \(ds_api.plans.features.feature.BaseFeature\)")] | None = None)
    

Holds a collection of features while retaining both their "individual" definition, and their definition within the context of a plan.

This is similar to a dictionary that maps the individual feature definition (ie, without the operator context), with the "full feature" (ie with the operator).
