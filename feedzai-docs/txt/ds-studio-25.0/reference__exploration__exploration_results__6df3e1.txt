###  `target` Â¶

|  |  tuple containing (target_field, target_value). Element target_field is the name of the target field. Element target_value indicate the value to be considered as 'positives'. Default: None. |  `(None, None)`  
  
###  `data` Â¶

|  `DataFrame | _TDataFrame | None` |  Pandas or PySpark DataFrame. A small sample (500 rows) will be stored as a Pandas DataFrame. If a target exists then the sample will be balanced with respect to the target value. This is useful for the sample section of the html report and to create scatter plots. Depending on the specification of parameter `sample_size`, this data will be used as well to compute the time dependencies. Default: None. |  `None`  
  
###  `sample_size` Â¶

|  `int | None` |  number of instances taken from `data` to use in the computation of time dependencies. If -1 is given then all instances will be used. If `None` then time dependencies won't be computed. Default: 100k. |  `100000`  
  
###  `report_html` Â¶

|  `str | None` |  an existing html report in string format. If None is passed it will generate it. It's mainly useful when creating an ExplorationResults from serialized results using the 'load' method. Default: None. |  `None`

###  `` generate_report Â¶
    
    
    generate_report(show_all_checks=False, embed_dependencies=False)
    

Generates an HTML report of the exploration results.

Parameters:

Name | Type | Description | Default  
---|---|---|---  
  
####  `show_all_checks` Â¶

|  |  Boolean value indicating whether all checks that were run should be displayed in the report, even if they triggered no warnings. Default is False. |  `False`  
  
####  `embed_dependencies` Â¶

|  |  Bolean value indicating if the report html file should include all css and js dependencies (bootstrap, jquery, vega). Embedding them increases significantly the size of the file, but in security-closed environments where there is no internet access, the dependencies might need to be embedded in order to be able to render the report. Default is False. |  `False`

Type | Description  
---|---  
`unknown` |  Overview report of the data in HTML format.
