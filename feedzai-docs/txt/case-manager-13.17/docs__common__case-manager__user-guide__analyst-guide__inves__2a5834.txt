# Review Alerts

Once you understand [what alerts that are up for review](/case-manager/13.17/docs/common/case-manager/user-guide/analyst-guide/investigating-alerts/accessing-alerts), you can use the details page of an event to start the investigation process This page helps you to understand the different alerts details displayed and how they can help you to classify alerts.

Case Manager can be configured to present either the **Classic** view or the **Modern** view of this page.
