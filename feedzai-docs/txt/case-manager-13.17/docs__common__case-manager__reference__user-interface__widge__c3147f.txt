# Notes

The `notes` widget is a Table widget preconfigured to display notes on a details page.

## Propertiesâ

The `notes` widget follows the [Table](/case-manager/13.17/docs/common/case-manager/reference/user-interface/widgets/table#properties) widget properties.

Notes visibility

Notes visibility can be configured according to the [`tenanted_notes`](/case-manager/13.17/docs/internal/case-manager/reference/core-config-json#cm) property.

Info

All properties can be overwritten.

## Default configurationâ
