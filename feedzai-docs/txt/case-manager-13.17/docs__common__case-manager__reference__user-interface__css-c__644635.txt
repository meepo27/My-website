## Buttonsâ

info

The button's color should not be applied directly with CSS but with the property kind instead: `default`, `success`, `warning`, `danger` or `info`.

Classes| Description  
---|---  
.fdz-css-button-border| Sets a transparent background with the border color of the button's kind.  
.fdz-css-button--link| Sets the button color to it's kind and removed shadow and background color.  
.fdz-css-button-block| Sets the button width to **100%**

## Floatsâ

Attention

Float usage to position elements is discouraged as [flexbox](https://developer.mozilla.org/en-US/docs/Web/CSS/CSS_Flexible_Box_Layout) provides a much more streamlined approach.

Classes| Description  
---|---  
.fdz-css-fr| Sets element to float **right**  
.fdz-css-fl| Sets element to float **right**  
.fdz-css-fn| Sets element to not float (**none**)
