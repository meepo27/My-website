# Access Groups

Access groups ensure that alerts/eventsÂ are only visible to those who should have access to it. For example, when teams from different countries use the same Case Manager, the alerts that enter the system should only be investigated by analysts from the same country as the alert. This ensures that the investigation complies with the rules for exposure of personal data during the investigation of financial crimes.
