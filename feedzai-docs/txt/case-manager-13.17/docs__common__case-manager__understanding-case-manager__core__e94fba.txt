# SLAs

Service Level Agreements (SLAs) allow to automatically perform actions on events and cases based on a time and schedule.

SLAs work similarly toÂ automation rules, following a When-If-Then structure, and allow you to have automated processes to distribute workload. For example, you can configure an SLA that sends an alert to a specific queue depending on the time that alert has been in the system.

Syntax Explanation

**When** two days have passed since activated, **if** the event has not been reviewed, **then** move the event to the _Urgent_ queue.
