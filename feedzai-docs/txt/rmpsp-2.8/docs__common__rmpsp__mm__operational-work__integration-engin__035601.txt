# Integration Guide

This guide provides you with the relevant steps to successfully test rules and test the system.

  * [Rule Testing](/rmpsp/2.8/docs/common/rmpsp/mm/operational-work/integration-engineer/integration-guide/rule-testing/overview): Learn how to test rules using the Postman Collection.
  * [User Acceptance Testing](/rmpsp/2.8/docs/common/rmpsp/mm/operational-work/integration-engineer/integration-guide/uat/overview): Learn how to test rules, and ensure the system is well configured / running properly.
