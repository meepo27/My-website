  * CASE_UPDATE: The case was updated

  * DELETE_NOTE: A note was removed from the case
  * CASE_QUEUE: The case was added/removed to/from a queue
  * CASE_STATE: The case state was changed
  * CASE_USER: The case was assigned/unassigned to/from a user
