# Check the Response via Pulse

Was this page helpful?Â 

Consider the case in which you triggered the Cards-Velocity-4 rule with five transactions in less than three minutes using the Card ID _fdz_testing_rules_1_. This generated a [response](/tfrb/latest/docs/common/tfrb/work-with-rules-and-lists/send-test-transactions/overview#response---rules-triggered) with an action code to list this card ID to be reviewed.

You can open the Pulse application to which you have submitted the request and check if the card was listed as expected:

  1. Go to the **Lists** tab.
  2. Open the _PosNeg Listed Cards_.
  3. Confirm if two Card ID _fdz_testing_rules_1_ items are enabled:



One item should contain the card ID tagged as **review** for a period of five days. While the other item should contain the card ID tagged as **decline** , with a date starting from the last review date. See the [Lists](/tfrb/latest/docs/common/tfrb/work-with-rules-and-lists/create-rules/lists#posneg-lists-in-pulse) page for more information about PosNeg lists.
