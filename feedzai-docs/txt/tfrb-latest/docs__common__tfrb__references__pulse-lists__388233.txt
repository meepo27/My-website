# Pulse Lists

Was this page helpful?Â 

Lists store sets of items and are available for rules to check the same pattern against a large number of values (e.g. a list of credit card numbers, a list of merchants).

In the process of fraud detection it's very common to define blacklists to block transactions from certain cards or to define common parameters in transactions that should be reviewed by analysts (triggering an alarm every time such transactions occur). Lists for grouping and managing these values so that they can be used in rules (check the [Rules Projects](/tfrb/latest/docs/common/tfrb/rules-projects/overview) page to learn more about how rules are organized in TFB).

info

Lists regarding sanctions are only relevant if you have Feedzai's Watchlist Transaction Screening solution enabled.
