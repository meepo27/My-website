# Requirements

## Service Requirementsâ

This service requires the following software to run.

### Java Environmentâ

OpenJDK SE Development Kit version 1.8, with the following vendors (with their latest hotfix versions):

  * Azul Zulu [rpm](https://maven.feedzai.com/repository/hsbc-releases/azul/zulu/8.68.0.21-ca-jdk8.0.362/zulu-8.68.0.21-ca-jdk8.0.362-linux.x86_64.rpm) [zip](https://maven.feedzai.com/repository/hsbc-releases/azul/zulu/8.68.0.21-ca-jdk8.0.362/zulu-8.68.0.21-ca-jdk8.0.362-linux.x86_64.zip) [tar.gz](https://maven.feedzai.com/repository/hsbc-releases/azul/zulu/8.68.0.21-ca-jdk8.0.362/zulu-8.68.0.21-ca-jdk8.0.362-linux.x86_64.tar.gz)
  * Azul Platform Prime (formerly Zing)
  * Amazon Corretto
  * Oracle



##### info

Product tests are done with the **Azul Zulu JVM**.

The following versions are not supported, and are known to have problems:

  * 1.8.0u242
  * 1.8.0u121
  * 1.8.0u60
  * 1.8.0u45 and earlier



Non-listed releases are either not supported or haven't been put to extensive testing.

## Setup Requirementsâ

### RDBMSâ

Batch Processor uses [PulseDB](https://github.com/feedzai/pdb) for database access, meaning that Batch Processor can be deployed on top of:

  * Oracle 19.3 (or higher)
  * PostgreSQL 14.20 (or higher) - driver version 42.7.10 should be used.
  * SQL Server 2017 GA (or higher)
  * H2 1.4.200 (or higher) - only for test/evaluation purposes.



##### info

Feedzai validates the product primarily against H2 and PostgresSQL.

##### caution

Before selecting a database engine, make sure you understand how different database systems are [supported by our PulseDB](https://github.com/feedzai/pdb/wiki/Quirks-specific-to-some-Database-systems).

### Reference Data Serviceâ

Batch Processor retrieves data from the Reference Data Service (RDS), and therefore requires an accessible RDS server to execute jobs. Read more about how to install and configure RDS in the [installation guide](/cs-hsbc-rma/0.2.0/docs/installation-guide/refdata/requirements-refdata).

### Pulseâ

Batch Processor sends data to Pulse, and therefore requires an accessible Pulse cluster to start. Read more about how to install and configure Pulse in the [installation guide](/cs-hsbc-rma/0.2.0/docs/installation-guide/pulse/requirements-pulse).
