# Default UDFs

Was this page helpful?Â 

Pulse comes with a set of User-Defined Functions (UDFs) that can be used in PQL expressions to implement richer logic than what's available from the basic built-in functions. This page provides an overview of the available UDFs.

To learn about how to use UDFs, see [Function Calls in PQL](/pulse/latest/docs/common/pulse/users-guide/feature-engineering/using-pql-in-features/function-calls-in-pql#udf-calls).

        amount,  // amount field  
        0.850,   // lower anchor means the raw score is more affected by the transformations
