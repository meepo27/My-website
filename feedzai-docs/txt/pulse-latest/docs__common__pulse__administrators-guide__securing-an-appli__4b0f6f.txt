# List of Permissions

The following sections list the permissions that are available to control access to resources of Pulse.

Resource dependencies

Resources sometimes have dependencies between them, hence to access one, you might need to have access to another. These dependencies are not always obvious. If you are having difficulties with resource permissions, contact Feedzai's technical support.

Name| Description  
---|---  
`*`| Permission that gives complete access to Pulse.

---|---

`admin:configuration:read`| Permission to read the configurations on the administration screens.

`admin:service:control`| Permission to start and stop services via the Administration API.

`admin:usermanagement`| Permission to manage users.
