# Data Types in Rules

RDL uses its own data types. When using a field or a list, the values get automatically converted to these data types. This topic describes the data types that RDL uses.

## Collectionsâ

RDL uses the following collections: lists, sets, maps, and tuples. They are the equivalent of the [complex data types](/pulse/latest/docs/common/pulse/understanding-pulse/core-concepts/data-sources/data-types#complex-fields) that you can use in the schema of a data source.

In RDL, the collection called map is the equivalent of a [list](/pulse/latest/docs/common/pulse/understanding-pulse/core-concepts/lists) created under **Lists** . Hence all collection operators can be used on them.

Best practice

Although it is possible to define collections directly in the rule using RDL, **the recommended method is to create a[list](/pulse/latest/docs/common/pulse/understanding-pulse/core-concepts/lists) outside of the rule, under Lists** . This way you can maintain the rules more easily, since a change in the list items does not imply the change and deployment of the whole rule.

Explicitly iterating over lists is not recommended

It is not recommended to iterate explicitly over Pulse lists (e.g., using filter, all, etc), as this is highly inefficient. Pulse lists are optimized for contains/lookup operations.
