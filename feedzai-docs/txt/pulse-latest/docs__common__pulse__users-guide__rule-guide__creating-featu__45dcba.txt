# PQL Data Types and Type Conversions

Was this page helpful?Â 

This topic gives you an overview of data types in PQL, and how to convert data from one data type to another.

PQL uses the following **primitive data types**.

string|

These data types are equivalent to the Java primitive data types. To see the exact definition or range for each, check the [Java documentation](https://docs.oracle.com/javase/tutorial/java/nutsandbolts/datatypes.html).

The **non-primitive data types** of PQL are:

  * Tuples
  * Collections:
    * Lists
    * Sets
    * Maps



Do not confuse these types with lists and map operators that you can create in the Pulse UI. They belong to two different levels of implementation. The non-primitive PQL data types are used only in PQL queries, when computing features. When the PQL computation is finished, Pulse stores the data of these non-primitive types as _Complex_ fields in the output data source.

## Converting dataâ

In PQL, each data field, constant, variable, or aggregation result is of a primitive data type. To convert from one data type to another, you can use the following options:

  * Cast operator, to cast a value of a numeric type into another numeric type. Learn more about this operator in the next section of this page.
  * The `str()` [built-in function](/pulse/latest/docs/common/pulse/users-guide/rule-guide/creating-features/using-pql-in-features/function-calls-in-pql#built-in-functions) to convert a numeric value to a string.
  * [User-defined functions (UDFs)](/pulse/latest/docs/common/pulse/users-guide/rule-guide/creating-features/using-pql-in-features/function-calls-in-pql#udf-calls). There are [built-in UDFs](/pulse/latest/docs/common/pulse/understanding-pulse/core-concepts/user-defined-functions) that can be used after creating an alias for them. Example: to convert the merchant category code to integer, you can use the `DataConversionTools.stringToInt()` function.



### Cast operatorâ

The cast operator allows you to cast values from a numeric type (int, long, float or double) to another numeric type. There is no built-in cast operator between numeric types and booleans or strings.

To cast a value, use the following syntax: `<value to convert>:<target type>`

Example: `Amount:int` is the value of the Amount field cast to integer.
