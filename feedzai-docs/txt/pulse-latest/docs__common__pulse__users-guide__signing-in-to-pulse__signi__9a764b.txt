# Resetting Two-Factor Authentication

Was this page helpful?Â 

## Whyâ

If you want to add Two-Factor authentication (2FA) to one or more devices or if you lost your mobile device in which 2FA was configured, you can reset the 2FA configuration. To reset 2FA you have to follow one of these scenarios:

  * Resetting 2FA of a signed in user: if you want to add more devices
  * Resetting 2FA of a user signed out with the reset key: if you lost your mobile device but you still have the reset key
  * Resetting 2FA of a user signed out without the reset key: if you lost your mobile device and you do not have the reset key.



The steps to reset 2FA for each of these scenarios are described below.

## How toâ

To reset 2FA execute the following steps according to the scenario that suits you.

### Resetting 2FA of a signed in userâ

  1. Navigate to the  Settings tool on Pulse UI to open the Settings menu

  2. Use the  **Reset Authentication** button to proceed to the reset the 2FA configuration.

  3. You are redirected to the sign in form. Enter you PIN code and use the  **Verify Code** button to finish the last step of reset your 2FA configuration.

  4. Your are redirected to the sign in form that requires configuration of 2FA on your mobile device. To learn how to configure 2FA on a mobile device check the page [Configuring Two-Factor Authentication](/pulse/latest/docs/common/pulse/users-guide/signing-in-to-pulse/signing-in-with-two-factor/configuring-two-factor-authentication).




### Resetting 2FA of a user signed out with the reset keyâ

  1. Access any Pulse URL to be redirected to the main Pulse sign in form.
  2. In this form, insert your Username and Password use the  **Sign in** button to continue to the next step.
  3. You are prompted with the sign in form associated with the second validation step to access Pulse. Insert the reset code, instead of using the PIN Code generated by your mobile device, and Reset Two-Factor Authentication.



You are prompted with an interface to configure 2FA on your mobile. For a full description on how to configure 2FA on your device check the Section [Configuring Two-Factor Authentication](/pulse/latest/docs/common/pulse/users-guide/signing-in-to-pulse/signing-in-with-two-factor/configuring-two-factor-authentication).

### Resetting 2FA of a user signed out without the reset keyâ

In this scenario, you have to request your Administrator to execute the reset of your 2FA configuration. The Administrator has an endpoint that allows disabling 2FA to a specific user. The following steps show how an Administrator can disable your 2FA configuration so that you can re-configure it again.

  1. The administrator navigates to the  Administration tool.

  2. The administrator open the  Security view.

  3. The administrator selects your user account to edit. The User form is opened with information regarding the **Status** of 2FA.

  4. in the User form, the administrator selects the  **Disable Authentication** button to reset your 2FA configurations on your mobile device(s).

  5. The Administrator is prompted with a warning window with the option  **Disable** to proceed with the reset.




Next time you sign in to Pulse you are requested to configure 2FA on your mobile device. To learn how to configure 2FA on a mobile device check the page [Configuring Two-Factor Authentication](/pulse/latest/docs/common/pulse/users-guide/signing-in-to-pulse/signing-in-with-two-factor/configuring-two-factor-authentication).
