# Selecting profiles

Was this page helpful?Â 

Pulse allows you to choose the profile that is more suitable for the Spark job that you want to run using the options below:

  * **Setting the default profile for the application** : allows you to set a profile that is used by default every time that you create any Data Science resource. You can look at this option as a global setting for the whole application.
  * Setting a default profile for a Job type: allows you to associate a profile to a Pulse resource (e.g. [Feature Importance](/pulse/latest/docs/common/pulse/understanding-pulse/core-concepts/models/feature-importance)). This option prevails over the application default.
  * **Selecting a profile/editing properties on demand, for a specific job** : allows you to choose a profile or edit properties directly when creating a specific Pulse resource. This option prevails over the other two, but only for the current resource that you are creating.



## Setting a profile as default for the Appâ

To set a profile as default for the whole application, perform the following steps:

  1. Select the **Jobs** tab to have access to the **Job Configuration Profile** list:

tip

By default, the **Jobs** tab is collapsed under the **Advanced Tabs** , and you need to use the  button to reach it.

  2. Locate the target profile that you want to choose as default, and select the **Star** button.




## Setting a profile as default for a Job typeâ

Preference over by default option

The option defining a profile by **Job type** prevails over the option Defining a profile by default.

To associate a profile to a **Job type,** access your application and execute the following actions:

  1. Select the **Jobs** tab to have access to the **Job Configuration Profile** table.

  2. Select the  button to have access to a list of **Resource Type** and **Job Profiles**.

  3. For each **Resource Type** choose a target **Job Profile**.

  4. Use the  button to save your configurations.




## Selecting or editing a profile on demandâ

Editing properties on demand

In addition to the selection on demand you can **edit the properties** on a selected profile for this Job Execution. To choose a profile, access your application and execute the following actions:
