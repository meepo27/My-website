# Evaluating your Sandbox Results

Was this page helpful?Â 

## Whyâ

Evaluating your Sandbox results against a test dataset is crucial in understanding how it is performing, and how close you are to reaching the objectives of your Data Science project.

Now that you have learned how to [create a Sandbox Evaluation](/pulse/latest/docs/common/pulse/users-guide/creating-a-data-science-project/testing-your-work-in-a-sandbox-environment/creating-a-sandbox-evaluation), you will need to generate a Sandbox Evaluation over a trained set of [Rules](/pulse/latest/docs/common/pulse/understanding-pulse/core-concepts/rules) and [Models](/pulse/latest/docs/common/pulse/understanding-pulse/core-concepts/models) and analyze the evaluation results.

## How toâ

To analyze the **Sandbox Evaluation** results, execute the following actions:

  1. In the  **Data Science tab** , select a **Sandbox Evaluation** from the **Sandbox Evaluations list.**

  2. Select an existing **Sandbox Evaluation**.




## Results by Scoreâ

The **Results by Score** focus on the field of the **Outcome Score** and the real final label. Based on that particular field, this allows you to understand the performance of your **Sandbox Evaluation**.

Therefore, you can understand how the system behaves independently of the outcome decision that was specified on the outcome decision field. For example, it will help you decide whether to change the score threshold for the final decision.

In the **Results by Score** tab, you can perform the following actions:

  1. Analyze the **ROC Curve** for the selected evaluation.

Exact values

Hover the mouse pointer over the plot line to inspect the exact values for the **Recall** and **FPR** metrics and the respective **Threshold**.

Cost-based Metrics

If you define a **Cost Field** , then the **ROC Curve** will also plot the values for _Cost-Recall_ vs. _Cost-FPR_.

  2. Configure the **X/Y Plot** to display a curve for any **X-Axis** and **Y-Axis**.

Exact values

Hover the mouse pointer over the plot line to inspect the exact values for the **X-Axis** and **Y-Axis** metrics and the respective **Threshold**.

  3. During the creation of a **Sandbox Evaluation,** you can select the breakdown for the metrics. Therefore, here you can see all the values for the metrics of the segmentation and its combinations. You can also change the threshold.

  4. Use the **View ROC curve** option to see which of the breakdown metrics can be seen in the ROC curve.

  5. You can also see the metrics per service for all the resources the **Sandbox Evaluation** has. This is useful for understanding the performance computation times of the resources analyzed in the sandbox. It helps you to grasp the performance gains or losses you will experience in your live Workflow and evaluate the tradeoffs. For instance, you can identify whether a Rules project takes too long (in the **Ind. Avg.**) whilst not adding much to the performance (by analyzing **Recall** and **FPR** metrics), therefore allowing you to consider whether to keep it.

  6. Export the results to a CSV file, if desired.




## Results by Outcomeâ

By analyzing the **Results by Outcome** , you can understand how the system behaves regarding the outcome decision that was specified on the outcome decision field. It works similarly to the **Results by Score** , but it does not provide a movable threshold. You can learn more about the performance of your Sandbox evaluation by analyzing these results:

  1. Select the outcome values to be shown either if `True` or `False`.
  2. You can export the results to a CSV, both **Per Breakdown** and **Per Services**



### Configurationâ

In the **Configuration tab,** you can see all the information regarding the **Sandbox Evaluation** you are seeing.

It contains all the information chosen in the creation of the Evaluation:

  * Data Source
  * Segments
  * Resources to Analyze
  * [Outcome Combinator](/pulse/latest/docs/common/pulse/understanding-pulse/core-concepts/outcome-combinator)
  * Additional Cost Field
  * Output Result Name and Directory Path
  * Time when the last update was made and who made it
