# Bundle structure

Was this page helpful?Â 

The bundle generated by the Export Resource option contains JSON files that are organized in separate folders according to resource type allowing easy management by different end-users. The content of the files is structured in a human readable format. This allows you to:

  * Quickly inspect the content of each file.
  * Add or delete any item of your resource list (e.g. add a **Rules Project** to the bundle).
  * Peer-review your resources.

Each folder contains a JSON file for each element added to the resource bundle.

Export Lists

**Lists** are always exported by default, and thus, the folder will contain a JSON file for each List that you have on your Pulse Application. However, you can choose to include the **List** items of each **List**.

## File structureâ

You can open JSON files using a standard editor to inspect the content. The table below provides the main key information that you can find inside in each file for each resource folder.

Folder| Description  
---|---  
lists| **Lists** are automatically exported. This folder contains a JSON file for each **List** that you have configured on your **Pulse App**.  
models| This folder contains a JSON file for each **Model** included in the resource bundle organized in separate folders for each **Model Project**.Note that you can include the binary of each **Model** when exporting the resources. In this case, the **Model Project** folder will contain the binary of each **Model.**  
plans| This folder contains a JSON file for each **Plan** included in the resource bundle.Note that you can include the execution of each **Plan** when exporting the resources. The metadata of the execution is stored within the file JSON file of the Plan.  
rulesProjects| This folder contains a JSON file for each **Rules Project** included in the resource bundle.Note that you can include a list of snapshots for each **Rules Project** when exporting the resources. The metadata of the snapshots is stored within the file JSON file of the Rules Project.  
tenantGroups| This folder contains metadata of the **Tenant Groups** that you have in your **Pulse app**.  
tenants| This folder contains metadata of the **Tenant** that you have in your **Pulse app**.
