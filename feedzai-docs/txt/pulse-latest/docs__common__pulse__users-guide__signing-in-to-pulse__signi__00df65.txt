# About Signing in with Two-Factor Authentication

Was this page helpful?Â 

Two-Factor Authentication (**2FA**) is a functionality that requires you to sign in with two pieces of information to verify your identity. **2FA** creates a more secure authentication system while complying with PCI-DSS security standards.

## Sign in stepsâ

When you access any Pulse URL, and you are not signed in yet, you are redirected to the main Pulse sign in form.

  1. In this form, insert your Username and Password and use the  button to continue to the authentication step.

  2. You are prompted with another form that requests a second step validation to access Pulse. Enter the PIN Code generated by the code generator that you are using on your mobile device, such as Google Authenticator. Use the  button to access Pulse.




Authentication failure

If you either introduce wrong credentials (username or password) or a wrong PIN Code, your are redirected to the first Sign in form (i.e. step 1) to start the sign in process again from the beginning. This occurs because 2FA provides authentication only if username/password/code are correct without giving any clue to which step the user failed. This is a 2FA requirement to comply with PCI-DSS security standards.

## Configuring 2FA on your deviceâ

To sign in with 2FA, a code generator application has to be configured on your mobile device(s). Pulse is agnostic to the application used to generate the code. As an example, the instructions to configure 2FA on your device using Google Authenticator are provided in page [Configuring Two-Factor Authentication](/pulse/latest/docs/common/pulse/users-guide/signing-in-to-pulse/signing-in-with-two-factor/configuring-two-factor-authentication).

## Resetting 2FA on your deviceâ

There are a number of scenarios in which you might want to reset the **2FA** configuration on your mobile device. Check the page [Resetting Two-Factor Authentication](/pulse/latest/docs/common/pulse/users-guide/signing-in-to-pulse/signing-in-with-two-factor/resetting-two-factor-authentication).
