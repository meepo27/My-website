# Configure Jetty to Log HTTP Requests

Was this page helpful?Â 

Pulse uses Jetty **9.4.X** as the back-end engine for the web server. It is possible to configure the engine to automatically log every HTTP request into a log file (which will appear in the `log/` folder). To do so, itâs necessary to add a new logger entry to the file `conf/engine/jetty/jetty.xml` in Pulse:
    
    
      <Configure id="Server" class="org.eclipse.jetty.server.Server">  
        <Arg name="threadpool"><New id="threadpool" class="org.eclipse.jetty.util.thread.QueuedThreadPool"/></Arg>  
        ...  
        <Set name="RequestLog">  
          <New id="RequestLog" class="org.eclipse.jetty.server.CustomRequestLog">  
            <!-- Writer -->  
            <Arg>  
              <New class="org.eclipse.jetty.server.AsyncRequestLogWriter">  
                <!-- Make http request log rotate by day. -->  
                <Arg><Property name="solr.log.dir" default="log"/>/yyyy_mm_dd.request.log</Arg>  
                <Set name="filenameDateFormat">yyyy_MM_dd</Set>  
                <!-- Only delete rotated files after a week.  -->  
                <Set name="retainDays">  
                  <Property name="solr.log.requestlog.retaindays" default="7"/>  
                </Set>  
                <Set name="append">true</Set>  
                <Set name="timeZone">UTC</Set>  
              </New>  
            </Arg>  
            <!-- Default format String: -->  
            <!-- Arg><Get class="org.eclipse.jetty.server.CustomRequestLog" name="EXTENDED_NCSA_FORMAT"/></Arg -->  
            <!-- Custom format String: https://javadoc.io/doc/org.eclipse.jetty/jetty-server/9.4.51.v20230217/org/eclipse/jetty/server/CustomRequestLog.html -->  
            <Arg>{{date: %{YYYY-MM-dd:hh:mm:ss:SSSZ}t},{response status:%s},{hostname: %{client}a}, {response time: %{ms}Tms}, {hostname: %{Host}i}, {user: %u}, {Connection status: %X}, {response status: %s}, {first line: %r}, {address client: %{client}a}, {address server: %{server}a}, {MAC: %{local}a}}</Arg>  
          </New>  
        </Set>  
      ...  
    

The API of`CustomRequestLog` for **Jetty v9.4.51.v20230217** (used by **Pulse 25.0.15+**) is described at [the jetty-server documentation](https://javadoc.io/doc/org.eclipse.jetty/jetty-server/9.4.51.v20230217/org/eclipse/jetty/server/CustomRequestLog.html).
