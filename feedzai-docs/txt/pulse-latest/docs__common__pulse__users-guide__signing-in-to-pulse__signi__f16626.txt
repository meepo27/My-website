# Configuring Two-Factor Authentication

Was this page helpful?Â 

## Whyâ

To sign in with Two-Factor Authentication (**2FA**), first you need to configure **2FA** on your mobile device to be able to generate a code that can be then entered in the sign in form.

In Pulse, 2FA uses Time-Based One Time Password (TOTP) to generate a temporary code. Learn more about [TOTP in Pulse](/pulse/latest/docs/common/pulse/users-guide/signing-in-to-pulse/signing-in-with-two-factor).

## How toâ

To configure **2FA** , execute the following steps:

  1. Access a Pulse URL. If you are not signed in yet you are redirected to the main Pulse Sign in form.

  2. In this form, insert your Username and Password and use the  **Sign in** button to continue to the next step.

  3. Your are prompted with an interface showing an alert that **2FA** has not been configured yet. Use the  **Configure** button to continue this process.

  4. To configure **2FA** on your device you have two options:

     1. Automatically, by reading the QR code using the code generator application on you device.

     2. Manually, by selecting the option _You can view the code and add it manually_ and typing on your mobile device the Account Key provided in the configuration interface.

  5. Insert the PIN code generated by the mobile application that you are using and finish this configuration by selecting the  **Register Application** button. If the PIN Code is valid, a new interface is displayed as shown in the figure below. The interface provides a reset code to reset the 2FA configuration. Learn more about [resetting **2FA**](/pulse/latest/docs/common/pulse/users-guide/signing-in-to-pulse/signing-in-with-two-factor/resetting-two-factor-authentication).

  6. Use the  **Go to Application** button to access Pulse.
