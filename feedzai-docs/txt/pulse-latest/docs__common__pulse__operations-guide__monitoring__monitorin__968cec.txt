# Monitoring Metrics

Was this page helpful?Â 

Pulse and App Engine instances collect monitoring metrics in different components that are then exposed through the `/metrics` endpoint. This endpoint has a default timeout of 1 second when retrieving the metrics from the App Engines. However, it's possible to use a timeout parameter to override this default. For example, calling `/metrics?timeout=3` will wait 3 seconds at most for metrics from the App Engines.

To give more visibility about these metrics to Pulse's operators, this section will hold pages describing these metrics.

Metrics Self Documentation

Even when not described in this section, all metrics have a short description and other information which can be obtained at the `/metrics/rich` endpoint.
