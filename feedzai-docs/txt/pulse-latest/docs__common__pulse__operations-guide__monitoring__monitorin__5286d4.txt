# Monitoring Replication of Events in the Workflow

Was this page helpful?Â 

When the event arrives to the end of a published workflow, it is replicated to other workflow replicas via a messaging broker.

The following table lists metrics available to monitor that execution:

Name | Description | Unit | Tags  
---|---|---|---  
Gauge

| The events that are waiting to be sent to the messaging broker to be replicated after having been processed normally in this workflow. | # | _workflowID

| The events that are waiting to be processed after having been received in a workflow replica from the messaging broker. They are delivered to this in-memory queue and are then posted to the workflow queue. | # | _workflowID  
appSlug
