# Comparing resource versions

Was this page helpful?Â 

## Whyâ

In a typical project, as you are evolving a given Pulse resource, a common workflow is to export the resource and version the bundle using a distributed version control system to keep track of the changes. At some point, you might have the need to compare the JSON file of two resource versions to check the differences between the versions.

The JSON files are structured in a human readable format that allows you to quickly compare changes between two files.

## How toâ

As a typical scenario, imagine that you need to compare a resource that is versioned in a storing system with a resource that is currently on your **Pulse app**. To do so, execute the following steps:

  1. Select the Options  button to open the application options menu:  

  2. Select the option â  to open the export wizard.
  3. Select the tab corresponding to the resource that you want to export.
  4. Add the resource that you want to compare to the export list.
  5. Use the button â  to save the resource bundle in your operating system.
  6. Use any standard software that allows comparing two JSON files. See the next subsections that cover examples of different use cases.
