# Monitoring DynamoDB Profile Store

Was this page helpful?Â 

When your application has workflows with scheduled metrics, they fetch the metric values from the profile store.

If your profile store uses DynamoDB, it's possible to access the following monitoring metrics.

Name | Description | Unit | Tags  
---|---|---|---  
Timers  
      
    
    pulse.workflow.profileStore.waitWorker

| Time waiting for a thread to handle the requests to DynamoDB. The number of threads is configurable via `profileStore.selectorThreads`. | seconds | _workflowID  
workflowDesc  
appSlug  
metricType  
appType  
elementId  
elementDesc_
