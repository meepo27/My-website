# Reviewing List Changes - Four Eyes Check

Was this page helpful?Â 

[Lists](/pulse/latest/docs/common/pulse/understanding-pulse/core-concepts/lists) provide a way to amplify the power of [rules](/pulse/latest/docs/common/pulse/understanding-pulse/core-concepts/rules) by allowing repetitive patterns to be defined as a single rule that then gets applied to a large number of values. Given the high level of automation that lists enable, ensuring every change is reviewed by a second pair of eyes helps prevent unwanted or unplanned changes from being published.

If the **Four-Eyes Check for Lists** functionality is enabled in your Pulse environment, changes to lists will not be published right away; instead, they will be queued for review. Such pending list changes only go live after a reviewer approves them.

Reviews of changes made to lists can be requested and performed directly in the Pulse interface. This page describes both sides of the review process: how to request a review for changes to lists, and how to perform such a review.

## Prerequisitesâ

To allow reviews of list changes, an administrator must set the `pulse.global.managedListsRevision.enabled` property to `true` in the Administration > Configuration view. The default value of this property is `false`.

Optionally, for the notification emails to work as designed, the following settings can be configured as well. However, if you don't intend to use the notification emails, these can be skipped:

  * The SMTP properties must be configured, so that the notification emails are properly sent.
  * The `pulse.global.managedListsRevision.notifications.email.from` property: sets the email address from which Pulse sends the notification email to the reviewers. By default, it's `[[email protected]](/cdn-cgi/l/email-protection)`.
  * The `pulse.global.ui.host` property is used to configure the URL where Pulse runs, and by default it's set to `http://localhost:8080/`. The notification email contains a link to the list changes that need to be reviewed, and the link starts with the URL set in this property. If the default value is not set to the actual value, the link in the email won't work.



Get in touch with Feedzai to set up four eyes check for lists in your Pulse environment.

### Set up a static e-mail to receive all Four Eyes Check notificationsâ

In addition to direct notifications sent to the author and reviewer in four eyes checks, Pulse allows setting up a static e-mail address which will receive all four eyes check notifications. This allows Pulse users to review the open revisions more thoroughly, and thus catch errors that might otherwise be missed. Note that the recipient of these emails will not be addressed directly, as they will be merely copies of the notifications sent to the author and reviewer of the corresponding four eyes check.

Notifying multiple users

This e-mail address can be set to that of a mailing list, which allows multiple users to receive every four eyes notifications.

To enable notifications for Pulse managed lists, provide the e-mail address via the following Pulse property: `pulse.global.managedListsRevision.notifications.email.staticreviewer`.

## Request a review for list changesâ

info

Users need to have the `application:managedlistitems:revision:create` [permission](/pulse/latest/docs/common/pulse/administrators-guide/securing-an-application#permissions) to request reviews of list changes from others.

To request a review of a change made to a list, perform the following steps:

  1. In the sidebar, select the  icon to open the **Lists** view.
  2. Select the list you want to make changes to.
  3. Make the desired changes to the list. For example, adding a new item, editing or deleting an existing item, or importing a batch of items from a CSV file.

caution

You won't be able to make changes to list items for which there are already pending changes. Attempting to do so will show an error message indicating the ID of the pending review.

  4. Optionally fill the **Notify users** field to indicate specific users you wish to inform of your review request. If the notification settings are properly configured, and the users have an email address associated with their Pulse account, they will receive an email message notifying them of the pending changes.
  5. Select the  button to add the changes to the review queue.  
A floating success message will be displayed, confirming that the changes have been submitted for review.
