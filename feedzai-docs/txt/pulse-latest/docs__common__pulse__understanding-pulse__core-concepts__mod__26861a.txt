# Cost Fields

A **cost field** is a field of the instances that is used as a weight for the metrics of the evaluations (of both models and rules), typically the transaction amount in a fraud detection scenario.

Using cost fields in model evaluations or rule evaluations allows you to transform any metric (which by default is count based, e.g. Recall, Precision, etc.) into a cost-based metric (e.g. Money Recall, if the field chosen is a form of cost of the instance).

Non-cost metrics weigh each transaction equally, with cost 1. Using a cost field gives it a weight that is proportional to the value of the field. e.g., money value.
