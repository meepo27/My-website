# Conditional Expressions in PQL

Was this page helpful?Â 

Conditional expressions of PQL return a value based on a condition.

Syntax:
    
    
    if <condition> then <then-case-expression> else <else-case-expression>  
    

Where:

  * `<condition>` is a boolean expression.

  * `<then-case-expression>` and `<else-case-expression>` are obligatory values.

If the condition is true, the conditional expression returns the value of the then-case-expression, otherwise the value of the else-case-expression.




Example:
    
    
    if( POSEntryMode == 'Swiped' or POSEntryMode == 'Keyed' or POSEntryMode == 'Chip' )  
      then 'Card Present'  
      else POSEntryMode
