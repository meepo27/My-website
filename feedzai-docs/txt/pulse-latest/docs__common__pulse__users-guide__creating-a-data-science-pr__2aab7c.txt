# Creating a Data Science project

Was this page helpful?Â 

Whether you are an experienced Data Scientist or still new to the job, learning how to use a new tool can seem a daunting task. This section of the User Guide will lead you through the several stages involved in your Data Science project and how to make the most out of Pulse.

It will help you how to map typical Data Science stages to Pulse, so that your learning curve is minimized, and you quickly get up to speed with Pulse. The main goal is to allow you to become more productive with Pulse than you already are with your current toolset. Pulse fully supports a complete [Data Science Loop](/pulse/latest/docs/common/pulse/understanding-pulse/core-concepts/data-science-loop).

Pulse, despite having fraud detection as a major use case, is completely problem-agnostic. This means that you can use Pulse to solve other types of problems, and apply the same Data Science approach to other domains and use cases.

## Using the Data Science tabâ

The **Data Science** tab  is the entry point for Data Science tasks in Pulse. It enables you to manipulate core Pulse concepts, such as [Data Sources](/pulse/latest/docs/common/pulse/understanding-pulse/core-concepts/data-sources) and [Plans](/pulse/latest/docs/common/pulse/understanding-pulse/core-concepts/plans), and assists you throughout all stages of your Data Science project.

The following image displays the Data Science tab :

The Data Science tab  contains the following sections:

  1. Data Sources

List with all configured [Data Sources](/pulse/latest/docs/common/pulse/understanding-pulse/core-concepts/data-sources) and respective analysis status. Select a Data Source to configure, examine and run analyses on your data. Use the Duplicate  option to avoid creating/recreating a Data Source from scratch.

  2. Plans

List with all configured [Plans](/pulse/latest/docs/common/pulse/understanding-pulse/core-concepts/plans) and respective type (Deployable or Non-Deployable). Select a Plan to design, edit and execute your data transformations. Use the Duplicate  option to avoid creating/recreating a Plan from scratch.

  3. Model Projects

List with all configured [Model Projects](/pulse/latest/docs/common/pulse/understanding-pulse/core-concepts/models). Select a Model Project to configure models and evaluations.

  4. Rules Projects

List with all configured [Rules Projects](/pulse/latest/docs/common/pulse/understanding-pulse/core-concepts/rules). Select a Rules Project to configure rules, templates, snapshots and evaluations.
