# HSBC-3212-Add-support-for-defining-allowed-PubSub-regions-in-DTP

### Add support for defining allowed Pub/Sub regions in DTPâ

FeatureFTMT-27702HSBC-3212

Also In:2.8.12.9.0

We've added support in the DTP for defining the allowed Pub/Sub regions where data may be stored and transmitted. This behaviour is controlled by three new Ansible variables:

  * `dtp_security_allowed_regions`: A list of allowed regions where data may be stored. Example:


    
    
    dtp_security_allowed_regions:  
      - europe-west1  
      - asia-east2  
    

Copy

  * `dtp_security_enforce_in_transit`: A boolean flag that enforces in-transit restrictions to the same regions defined for storage.
  * `dtp_security_regional_endpoint`: The regional Pub/Sub gRPC service endpoint to use.



Please refer to the [Data Security section](/cs-hsbc/3.0.2/docs/installation-guide/dtp/service-dtp#data-security) in the DTP Configuration page for more details.
