# HSBC-3358-Allow-concurrent-Pulse-application-publishes

### Allow concurrent Pulse application publishesâ

FeatureFTMT-29333HSBC-3358

The number of concurrent application publishes in Pulse will now be set to the number of applications configured in the `apps_enabled` variable, so that for instance inbound and outbound can be published concurrently. Specifically, this change sets the `pulse.global.services.core.apps.operationThreadPoolNumberOfThreads` property in Pulse.
