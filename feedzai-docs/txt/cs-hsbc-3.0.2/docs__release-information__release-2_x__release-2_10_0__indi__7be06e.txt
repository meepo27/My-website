# HSBC-3086-Change-deployment-pipelines-to-support-RHEL8-

### Change deployment pipelines to support RHEL8+â

FeatureFTMT-26831HSBC-3086

Also In:2.8.32.9.2

We've changed the Case Manager, Pulse and ETL deployment pipelines to support installations on RHEL8+ that were failing due to restrictions on the `rsync` module execution.

By default the pipelines will still have the previous behaviour. This can be changed during deployment by setting the `use_rsync` Ansible variable to `false`.

For more details please refer to:

  * [Case Manager Recommendations](/cs-hsbc/3.0.2/docs/installation-guide/casemanager/configuration-casemanager)
  * [Pulse Configuration Recommendations](/cs-hsbc/3.0.2/docs/installation-guide/pulse/configuration-pulse)
  * [ETL Configuration Recommendations](/cs-hsbc/3.0.2/docs/installation-guide/etl/configuration-etl)
