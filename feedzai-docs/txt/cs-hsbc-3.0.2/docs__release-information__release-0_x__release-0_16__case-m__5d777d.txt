## Implement integration between Pulse and Case Manager regarding treatment strategyâ

Feature

Add new _outcome_ to Workflow - `treatment_strategy` \- defaulting to `none` (manual). This outcome is core to the [Case Manager Workflow MVP](/cs-hsbc/3.0.2/docs/guides/casemanager/overview).

## Replace Status Reasonsâ

Rework

Changed existing Case Manager Status Reasons according to HSBC request. Note that, since there's no Status Reason for Digital Activity and one is mandatory to mark as Fraud / Not Fraud, currently it's not possible to mark digital activity events.

With that in mind, a _Fraud Prevention Manager_ can add new Status Reasons to allow the previous behavior.
