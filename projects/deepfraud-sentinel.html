Problem Statement

Card payment fraud at Societe Generale required a decision within 100 ms of transaction initiation — too tight for complex deep learning models to run alone. Meanwhile, the existing gradient-boosted model lacked behavioural memory: it scored each transaction in isolation, missing fraud patterns that only emerge across a sequence of 20–30 transactions.

The solution was a two-stage ensemble: a fast XGBoost scorer gates all transactions, while a BiLSTM models the sequence of the last 30 transactions for behavioural anomalies. The ensemble combines both scores with learned weights, calibrated on a stratified validation set.

System Architecture

Kafka Transaction Stream → Redis Feature Cache → XGBoost (fast path) → BiLSTM + Attention → Calibrated Ensemble → Accept / Flag / Block

Velocity and behaviour features (rolling 1 h / 24 h counts, amount z-score, merchant risk, geo-velocity) are pre-computed and cached in Redis with sub-millisecond lookups. The XGBoost model uses these as inputs and runs in ~5 ms.

For high-risk transactions (XGBoost score > 0.3), the last 30 transactions are fetched from Redis and scored by the BiLSTM. Multi-head attention lets the model focus on the most suspicious moments in the sequence. The final ensemble score uses 0.45 × XGB + 0.55 × LSTM weights tuned on a validation holdout.

Key Implementation

features.py — Velocity and behavioural feature engineering Python · Pandas · NumPy 
import pandas as pd
import numpy as np

def engineer_features(df: pd.DataFrame) -> pd.DataFrame:
    df = df.copy()
    df['timestamp'] = pd.to_datetime(df['timestamp'])
    df = df.sort_values(['account_id', 'timestamp'])

    # Rolling velocity (per-account, indexed by timestamp)
    grp = df.groupby('account_id')
    df['tx_count_1h']   = grp['amount'].transform(
        lambda x: x.rolling('1H',  on=df.loc[x.index, 'timestamp']).count())
    df['tx_count_24h']  = grp['amount'].transform(
        lambda x: x.rolling('24H', on=df.loc[x.index, 'timestamp']).count())
    df['amount_sum_1h'] = grp['amount'].transform(
        lambda x: x.rolling('1H',  on=df.loc[x.index, 'timestamp']).sum())

    # Behavioural deviation: z-score vs account history
    stats = df.groupby('account_id')['amount'].agg(['mean', 'std'])
    df    = df.join(stats, on='account_id', rsuffix='_acct')
    df['amount_zscore'] = (df['amount'] - df['mean']) / (df['std'].clip(lower=1e-8))

    # Temporal signals
    df['hour']       = df['timestamp'].dt.hour
    df['is_weekend'] = df['timestamp'].dt.dayofweek.isin([5, 6]).astype(int)
    df['is_night']   = df['hour'].isin(range(0, 6)).astype(int)
    return df
model.py — BiLSTM with multi-head attention over 30-transaction sequences Python · PyTorch 
import torch
import torch.nn as nn

class FraudBiLSTM(nn.Module):
    def __init__(self, input_size=15, hidden=128, layers=2, dropout=0.3):
        super().__init__()
        self.lstm = nn.LSTM(
            input_size=input_size,
            hidden_size=hidden,
            num_layers=layers,
            batch_first=True,
            bidirectional=True,
            dropout=dropout,
        )
        # Multi-head attention over the BiLSTM output (hidden*2)
        self.attn = nn.MultiheadAttention(
            hidden * 2, num_heads=4, batch_first=True, dropout=0.1
        )
        self.head = nn.Sequential(
            nn.LayerNorm(hidden * 2),
            nn.Linear(hidden * 2, 64),
            nn.GELU(),
            nn.Dropout(dropout),
            nn.Linear(64, 1),
        )

    def forward(self, x):
        # x: (B, seq=30, features)
        out, _    = self.lstm(x)               # (B, 30, 256)
        ctx, _    = self.attn(out, out, out)   # attended context
        pooled    = ctx.mean(dim=1)            # global avg pool
        return self.head(pooled).squeeze(-1)


def ensemble_score(xgb_model, lstm_model, feats_df, seq_tensor):
    xgb_score  = xgb_model.predict_proba(feats_df)[:, 1]
    lstm_model.eval()
    with torch.no_grad():
        lstm_score = torch.sigmoid(lstm_model(seq_tensor)).cpu().numpy()
    # Weights tuned on validation holdout
    return 0.45 * xgb_score + 0.55 * lstm_score
