Problem Statement

Traditional rule-based AML systems flag individual transactions in isolation. Mule networks exploit this blind spot by distributing illicit flows across dozens of seemingly normal accounts — each individual transaction looks benign, but the relational structure betrays the scheme.

HSBC needed a system that could reason over the full transaction graph to identify coordinated mule rings, generate explainable risk narratives for compliance teams, and integrate seamlessly into the existing case-management workflow — all within strict regulatory constraints (FCA, PRA).

System Architecture

Transaction Ledger → Graph Builder (PyG HeteroData) → 3-Layer GraphSAGE → Risk Scorer → GPT-4 Narrative → Case Management

The pipeline builds a heterogeneous graph where account nodes are connected by directed fund-transfer edges. Node features encode account history; edge features encode transaction amount, timing, and merchant category. Three GraphSAGE convolution layers aggregate neighbourhood information before a binary classifier labels each node as mule / not mule.

A class-imbalanced training regime (positive-weight BCELoss, ~1% mule prevalence) combined with focal loss prevents the model from collapsing to the majority class. All flagged accounts are passed to a GPT-4 Turbo (Azure OpenAI) chain that generates plain-English risk narratives, cutting analyst write-up time by 60%.

        dtype=torch.float
    )

    # Edge indices + features

    dst = [acc_map[r] for r in transactions_df['receiver_id']]
    edge_index = torch.tensor([src, dst], dtype=torch.long)

    edge_feats = torch.tensor(
        transactions_df[[
            'amount', 'hour', 'day_of_week', 'is_round_amount'
        ]].values,
        dtype=torch.float
    )

    G['account'].x = node_feats
    G['account', 'transfers_to', 'account'].edge_index = edge_index
    G['account', 'transfers_to', 'account'].edge_attr  = edge_feats
    return G
model.py — 3-layer heterogeneous GraphSAGE classifier Python · PyTorch 
from torch_geometric.nn import SAGEConv, HeteroConv
import torch.nn as nn
import torch.nn.functional as F

class FinGuardGNN(nn.Module):
    def __init__(self, in_channels, hidden_channels=128, num_layers=3):
        super().__init__()
        self.convs = nn.ModuleList()
        self.bns   = nn.ModuleList()

        for i in range(num_layers):
            in_ch = in_channels if i == 0 else hidden_channels
            conv  = HeteroConv({
                ('account', 'transfers_to', 'account'): SAGEConv(
                    (in_ch, in_ch), hidden_channels, normalize=True
                )
            }, aggr='mean')
            self.convs.append(conv)
            self.bns.append(nn.BatchNorm1d(hidden_channels))

        self.classifier = nn.Sequential(
            nn.Linear(hidden_channels, 64),
            nn.ReLU(),
            nn.Dropout(0.3),
            nn.Linear(64, 1)   # binary: mule / not mule
        )

    def forward(self, x_dict, edge_index_dict):
        for conv, bn in zip(self.convs, self.bns):
            x_dict = conv(x_dict, edge_index_dict)
            x_dict = {k: F.relu(bn(v)) for k, v in x_dict.items()}
        return self.classifier(x_dict['account'])


def train(model, graph, labels, epochs=50):
    optimizer  = torch.optim.Adam(model.parameters(), lr=1e-3, weight_decay=1e-5)

narrative.py — GPT-4 risk narrative generator for analysts Python · LangChain · Azure OpenAI 
from langchain_openai import AzureChatOpenAI
from langchain.prompts import ChatPromptTemplate

PROMPT = ChatPromptTemplate.from_template("""
You are a financial crime analyst assistant at a major UK bank.
Based on the graph-based risk signals below, write a concise
risk narrative (3-4 sentences) for the fraud investigation team.

Account:           {account_id}
GNN Risk Score:    {risk_score:.1%}
Connected Accounts:{connected_count}
Circular Flow:     {has_circular}
Avg Tx Amount:     £{avg_amount:,.0f}
Rapid Txs (<1 hr): {rapid_count}

Write a professional summary highlighting the key red flags.
""")

def generate_risk_narrative(account_id, gnn_score, features):
    llm    = AzureChatOpenAI(deployment_name="gpt-4-turbo", temperature=0)
    chain  = PROMPT | llm
    result = chain.invoke({
        "account_id":      account_id,
        "risk_score":      gnn_score,
        "connected_count": features["connected_count"],
        "has_circular":    features["has_circular_flow"],
        "avg_amount":      features["avg_amount"],
        "rapid_count":     features["rapid_transactions"],
    })
    return result.content
