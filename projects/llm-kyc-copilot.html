Problem Statement

KYC onboarding at HSBC required analysts to manually review identity documents (passports, utility bills, corporate filings), cross-reference against watchlists, and write a risk justification — a process taking 30-90 minutes per customer.

The goal was to automate document ingestion, risk reasoning, and structured report generation while maintaining a full audit trail and ensuring every output was explainable and overridable by a human compliance officer.

System Architecture

ID Docs (PDF / Image) → pytesseract OCR → Pinecone (per-customer namespace) → GPT-4 JSON Risk Classifier → KYCRiskReport (Pydantic) → Compliance Portal

Each customer's documents are OCR-processed and stored in a dedicated Pinecone namespace, ensuring complete data isolation between customers. At classification time, the top-8 most relevant passages are retrieved for the customer and injected into a structured GPT-4 prompt that returns a strict JSON response.

The JSON output is validated against a Pydantic KYCRiskReport schema before being written to the compliance portal, ensuring the LLM can never produce malformed or missing fields — a critical requirement for regulatory audit trails.

Key Implementation

ocr.py — PDF/image identity document ingestion via pytesseract Python · pytesseract · pdf2image 
import pytesseract
from PIL import Image
from pdf2image import convert_from_path
from langchain.schema import Document

def ocr_identity_document(file_path: str) -> list[Document]:
    """Extract text from passports, driver licences, utility bills."""
    if file_path.endswith(".pdf"):
        images = convert_from_path(file_path, dpi=300)
    else:
        images = [Image.open(file_path)]

    docs = []
    for i, img in enumerate(images):
        text = pytesseract.image_to_string(img, lang="eng")
        docs.append(Document(
            page_content=text,
            metadata={
                "source": file_path,
                "page":   i + 1,
                "type":   "identity_doc",
            }
        ))
    return docs
kyc_chain.py — Risk classification with structured JSON output Python · LangChain · Azure OpenAI · Pydantic 
from langchain_openai import AzureChatOpenAI
from langchain.chains import RetrievalQA
from langchain.prompts import PromptTemplate
from pydantic import BaseModel
import json, os

class KYCRiskReport(BaseModel):
    customer_id:    str
    risk_tier:      str      # "LOW" | "MEDIUM" | "HIGH"
    risk_score:     float    # 0.0 – 1.0
    key_concerns:   list[str]
    recommendation: str      # "APPROVE" | "ENHANCED_DUE_DILIGENCE" | "REJECT"
    reviewer_notes: str

KYC_PROMPT = PromptTemplate(
    input_variables=["customer_id", "context"],
    template="""You are a KYC compliance officer at a major UK bank.
Analyse the following customer documents and return ONLY valid JSON.

Customer ID: {customer_id}
Documents:
{context}

Return this exact JSON schema (no markdown, no extra text):
{{
  "risk_tier":      "LOW" | "MEDIUM" | "HIGH",
  "risk_score":     <float 0.0-1.0>,
  "key_concerns":   ["concern1", "concern2"],
  "recommendation": "APPROVE" | "ENHANCED_DUE_DILIGENCE" | "REJECT",
  "reviewer_notes": "<brief explanation for compliance team>"
}}""",
)

def run_kyc_analysis(customer_id: str, docs, vectorstore) -> KYCRiskReport:
    # Index docs under this customer's private namespace
    vectorstore.add_documents(docs, namespace=customer_id)
    retriever = vectorstore.as_retriever(
        search_kwargs={"k": 8, "namespace": customer_id}
    )
    llm   = AzureChatOpenAI(
        azure_deployment="gpt-4-turbo", temperature=0,
        model_kwargs={"response_format": {"type": "json_object"}},
    )
    chain = RetrievalQA.from_chain_type(
        llm=llm, retriever=retriever,
        chain_type_kwargs={"prompt": KYC_PROMPT},
    )
    raw    = chain.invoke({"query": f"KYC risk for {customer_id}",
                           "customer_id": customer_id})
    data   = json.loads(raw["result"])
    return KYCRiskReport(customer_id=customer_id, **data)
