Problem Statement

HSBC's compliance teams manage hundreds of regulatory documents — FCA handbooks, PRA rulebooks, internal AML policies, Basel accords, and more. Answering a single compliance question routinely required a lawyer or senior analyst to spend 2-4 hours searching, cross-referencing, and drafting a response.

The goal was to reduce that to seconds while guaranteeing every answer cites the exact source document and page number — critical for audit trails and regulatory defensibility.

System Architecture

PDF / Word Docs → PyPDF Loader + Chunker → text-embedding-3-large → ChromaDB (persistent) → MMR Retriever → GPT-4 Turbo (stuff chain)

Documents are chunked with 800-token windows and 150-token overlap using RecursiveCharacterTextSplitter. Chunks are embedded with text-embedding-3-large (3072 dimensions) and stored in a persistent ChromaDB vector store. At query time, Maximum Marginal Relevance (MMR) retrieval fetches 6 diverse chunks from a 20-candidate pool, preventing semantically duplicate passages from dominating the context window.

A custom compliance prompt forces the LLM to cite the exact document title and page number for every claim and to explicitly say "Insufficient information" when the context doesn't support an answer — avoiding hallucination in a regulated environment.

Key Implementation

ingest.py — Document loading, chunking, and vector store build Python · LangChain · ChromaDB 
from langchain_community.document_loaders import PyPDFDirectoryLoader
from langchain.text_splitter import RecursiveCharacterTextSplitter
from langchain_openai import OpenAIEmbeddings
from langchain_chroma import Chroma

def ingest_documents(docs_path: str, persist_dir: str = "./chroma_db"):
    # 1. Load all PDFs
    loader   = PyPDFDirectoryLoader(docs_path)
    raw_docs = loader.load()
    print(f"Loaded {len(raw_docs)} pages from "
          f"{len({d.metadata['source'] for d in raw_docs})} documents")

    # 2. Chunk with overlap for context continuity
    splitter = RecursiveCharacterTextSplitter(
        chunk_size=800,
        chunk_overlap=150,
        separators=["\n\n", "\n", ". ", " "],
    )
    chunks = splitter.split_documents(raw_docs)
    print(f"Split into {len(chunks)} chunks")

    # 3. Embed and persist
    embeddings  = OpenAIEmbeddings(model="text-embedding-3-large")
    vectorstore = Chroma.from_documents(
        documents=chunks,
        embedding=embeddings,
        persist_directory=persist_dir,
        collection_name="regulatory_docs",
    )
    print(f"Vector store: {vectorstore._collection.count()} vectors")
    return vectorstore
rag_chain.py — MMR retrieval + citation-enforcing compliance prompt Python · LangChain · GPT-4 Turbo 
from langchain.chains import RetrievalQA
from langchain_openai import AzureChatOpenAI
from langchain.prompts import PromptTemplate

COMPLIANCE_PROMPT = PromptTemplate(
    input_variables=["context", "question"],
    template="""You are a regulatory compliance expert at a major UK bank.
Answer using ONLY the provided context. Cite document title and page number
for every factual claim. If the context is insufficient, respond:
"Insufficient information in the provided regulatory documents."

Context:
{context}

Question: {question}

Answer (with citations):""",
)

def build_rag_chain(vectorstore):
    retriever = vectorstore.as_retriever(
        search_type="mmr",              # diverse retrieval
        search_kwargs={"k": 6, "fetch_k": 20},
    )
    llm = AzureChatOpenAI(
        azure_deployment="gpt-4-turbo",
        temperature=0,
        max_tokens=800,
    )
    return RetrievalQA.from_chain_type(
        llm=llm,
        chain_type="stuff",
        retriever=retriever,
        chain_type_kwargs={"prompt": COMPLIANCE_PROMPT},
        return_source_documents=True,
    )

# Usage
chain  = build_rag_chain(vectorstore)
result = chain.invoke({
    "query": "What are the AML transaction monitoring thresholds "
             "under FCA SYSC 6.3?"
})
print(result["result"])
for doc in result["source_documents"]:
    print(f"  → {doc.metadata['source']} p.{doc.metadata.get('page','?')}")
